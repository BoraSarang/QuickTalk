포인터 pill은 “새 대화의 입구”

단축키를 눌렀을 때, 마지막 대화가 이어가기 시간(예: 5분) 안이면 지금처럼 대화 창이 뜹니다. 시간이 지났으면 빈 대화 창 대신 포인터 자리의 pill이 뜨고, 질문을 넣으면 대화 창으로 넘어갑니다.

05 승인 시 확정할 값

표시 조건이어가기 시간이 지난 뒤 단축키를 눌렀을 때만 pill. 그 안이면 지금처럼 대화 창.
기준 시간설정 › 일반의 “이어가기” 값 그대로 (0 = 사용 안 함 → 항상 pill? 또는 항상 새 대화 — 확인 필요)
대화 창pill이 뜰 때 빈 대화 창은 만들지 않음. 질문을 보낼 때 새 대화를 만들고 창을 연다.
Enter입력한 질문을 보내며 대화 창으로 전환. 빈 입력이면 무시.
