설계 메모

상태
  1. 1카드는 입력독 위에 겹쳐 뜹니다. 대화 본문을 밀거나 스크롤을 튀게 하지 않습니다.
  2. 2기본 버튼은 [교정해서 보내기]. Enter로 실행하고, ⌥Enter는 원문 그대로 보냅니다.
  3. 3[이 대화에서 끄기]는 이 대화에서만. 설정의 기본값은 유지됩니다.
  4. 4검사는 전송 직전, 온디바이스 규칙으로 5ms 이하. 네트워크를 쓰지 않습니다.

설계 메모

  1. 1380pt 폭에 맞춰 2줄까지만 보여 주고, 나머지는 ‘+N곳’으로 접습니다.
  2. 2Enter = 교정해서 보내기, ⌥Enter = 그대로. ⌘Return은 지금처럼 대화 창을 엽니다.
  3. 3화면 위쪽에서도 보이는 영역 안으로 클램프합니다. 포커스는 빼앗지 않습니다.
  4. 4Esc는 카드만 닫고 pill은 유지합니다. 한 번 더 누르면 pill이 닫힙니다.
