## 0. 현재 구현 요약 (2026-10-21, v0.17 기준)
- **대화 창**: 독립 `NSPanel`, 가변(최소 420×420·크기 기억), 기본 레벨 `.normal`, 📌=항상 위, 🔖=보관. 시작 시 마지막 대화 복원. 열 때/이어갈 때 스크롤은 맨 아래.
- **입력**: Siri형 한 상자(1~5줄, Enter 전송 / Shift+Enter 줄바꿈), 🎤 받아쓰기, ↑ 전송. 첨부 진입점은 **QuickShelf 하나**.
- **답변**: 마크다운 렌더(AI만, 복사·저장은 원문) + **스트리밍**(OpenAI SSE / Ollama NDJSON, 80ms 스로틀) + 자동 스크롤 + 📋 복사 / 🔊 읽어주기 / 응답 시간. 사용자 질문의 `⋯`(다시 응답·질문 수정)는 말풍선 **오른쪽·세로 중앙**.
- **기록**: 모든 대화 `history.json` 자동 저장, 보관 우선 정렬, `keepDays`(기본 30일), 보관함 탭 = 진행 중 + 대화 기록. 검색 결과 클릭 → 일치 턴 포커스 + 테두리 깜빡임.
- **제목**: 첫 질문에서 자동 생성(30자), 대화 헤더/보관함에서 변경(`RenameSheet`). 직접 바꾼 제목은 자동 생성이 덮지 않음.
- **삭제**: 보관함 휴지통·설정 [기록 모두 지우기] 모두 **자체 확인 시트**(`DeleteConfirmSheet`) — 취소 기본(Esc), 빨간 삭제, Enter 미동작.
- **설정**: 전면 설정 7탭(일반/단축키/퀵셸프/AI/음성/보관함/정보), 대화 창 설정 탭은 **창 폭에 맞춰 가로 가변**, 선택 모델 **[연결 테스트]**. 짧은 설정 화면의 하단 패딩은 줄였고 기본 창 높이는 유지한다.
- **QuickShelf**: **화면 가장자리 핸들 없음** — `⇧⌥V`·헤더 버튼·대화창 안 오버레이(폭 300, 창 폭은 그대로) 3탭. 클립보드(2분·5개·민감 마스킹) / 파일·이미지 / 캡처. 캡처 3모드(전체·드래그·윈도우), **Space 모드 전환**, Esc 취소, 십자 커서. 캡처 카드 호버 시 **복사·저장·Finder 툴바**. **첨부로 사용한 파일·캡처 카드는 목록에서 사라진다**(파일 원본은 유지, 캡처는 임시 복사 후 원본 삭제).
- **음성**: Apple STT/TTS, Whisper 로컬(mlx-whisper·whisper.cpp), Edge TTS, Piper. 언어·목소리·속도·미리 듣기.
- **단축키**: 전역 5종(대화 `⌘Space`, 퀵셸프 `⇧⌥V`, 캡처 `⌥⇧3`/`⌥⇧4`/`⌥⇧⌘4`) + 설정에서 녹화 변경·충돌 안내.
- **AI**: Apple FM / Ollama / OpenAI 호환. 오류는 `E-MAC-*` 코드와 **어느 서버가 왜** 실패했는지 표시(본문 비노출). `E-MAC-NET-0003`은 모델/업스트림 5xx — 예: HTTP 503·`server_error`는 모델 서버 과부하·점검·프록시 오류. 말풍선·연결 테스트는 원인+HTTP+서버 코드+host, 상태 카드는 `HTTP 503 · server_error — 모델 서버 과부하·점검·프록시 오류 가능. 잠시 후 재시도하거나 다른 모델을 선택하세요`처럼 2줄로 표시.
- **웹 검색**: 답변 방식 3종 — ① **검색 결과 주입**(기본, 모든 프로바이더: 모델 Y/N 판정 → Exa 3~8건 주입 → 스트리밍) ② **툴 콜링**(OpenAI 호환 `web_search` 도구, 모델이 검색어 작성, 미지원 시 자동 폴백) ③ **Exa `/answer`**(답변 초안+인용을 참고로 주입, 실패 시 `/search` 폴백). 공통으로 `[n]` 인용(클릭=출처)·출처 카드·**판정/검색/`answer` 10분 캐시**·[웹에서 찾기]·**하루 한도(기본 50회, 캐시 적중 제외)**·비차단 경고(`E-MAC-SEARCH-*`). 검색 컨텍스트는 입력 예산의 1/3로 자르고 실제 토큰으로 기록을 재조정한다. 🌐는 그 질문만 강제.
- **공통 메모리**: 설정 › AI에서 **모든 대화에 적용되는 사용자 작성 사실**을 여러 개 관리(추가·편집·삭제·사용 토글·순서·태그·검색·JSON 가져오기/내보내기). 방식 = **항상 모두**(기본) / **관련 항목만**(로컬 해시 임베딩 + 태그, `항상 포함` 예외), 토큰 예산 400/800/1600/3200(기본 800). 요청은 `공통 메모리 → 대화 요약 → 최근 원문 → 검색 → 질문` 순서. 대화 헤더 🧠로 **그 대화에서만** 끌 수 있고, 토큰 예산은 대화 기록 예산에서 먼저 예약한다. 저장 `memory.json`(원자적 쓰기·`0600`, 손상 시 `memory.json.corrupt`), 원격 전송·민감정보 경고. 항목 임베딩은 128개 캐시.
- **대화 기억**: 입력 예산의 **70%**를 넘으면 답변 후 **백그라운드**로 오래된 턴을 요약한다. 이후 요청은 `요약 + 경계 이후 최근 원문`만 전송하고, **원문은 화면·보관함·검색에서 그대로** 남는다. 최근 원문 기본 6개(Apple FM 4개), `/compact`는 보조 명령, 요약 해제 시 자동 정리를 일시 중지하고 [다시 켜기]로 재개. **최근 원문 자체가 예산을 넘으면 오래된 턴을 요청에서 강제 제외**하고 배너로 알린다. [보기] 시트에서 **요약 직접 편집** 가능(경계·일시 중지 유지). **[보기]는 입력독 위 배너와 설정 › AI › 대화 기억 정리 두 곳**에 있다.
- **미구현**: 대화 기록 전체의 장기 기억 검색(공통 메모리와 별개), 모델 임베딩 기반 관련성, 툴 콜링 다중 왕복, QuickShelf 주석·스크롤 캡처·OCR, T-21 포인터 pill, H3 다크/틴티드 아이콘 에셋 — `docs/plans/PLAN_v0.14_websearch_macos.md`, `PLAN_v0.15_memory_macos.md`, `PLAN_v0.16_common_memory_macos.md`.

## 4. 시스템 UI는 native, 앱 자체 UI는 custom
- 시스템 설정 창(SettingsView)·디버그 패널·권한 요청·시스템 다이얼로그는 macOS 네이티브 규칙 준수
- 그 외 앱 자체 화면(대화 창·대화 창 설정 탭·메뉴바 Hub)은 **custom**: 네이티브 `Picker`/`NSPopUpButton` 대신 자체 카드 스타일로 그린다
  - 이유: design_profile = custom(자체 디자인 시스템). 시스템 컨트롤을 쓰면 카드 스타일과 어긋나고 폭·정렬도 따로 놀았다
  - 선택 컨트롤 규칙: 라디오 행(프로바이더) 또는 자체 드롭다운(현재 값 행 + `⌄`, 펼치면 카드 안 목록). 가로는 항상 카드 폭을 꽉 채운다
- 설정 항목: `메뉴바에 표시`(PopClip식 on/off, off면 단축키 전용) + `Dock에 표시` 토글 포함
- 표시 정책: 메뉴바·Dock을 모두 숨기면 진입점이 사라지므로 최소 1개를 강제한다(메뉴바 숨김 → Dock 자동 ON, Dock 숨김 → 메뉴바 자동 ON)

## 5. AI 프로바이더 (v0.10 확장 목록)
- 구조: `LLMProviderConfig { id, name, type, baseURL, model, secretID, enabled }` 목록 + `activeProviderID`
- 기본 3종 시드: `local-apple-fm`(기본 활성) / `local-ollama`(localhost:11434) / `remote-openai`(192.168.86.30:8791/v1)
- 추가/삭제/편집 자유. 원격(OpenAI 호환)은 주소·모델·키가 필요하고, 키 없는 원격이 활성이면 Apple FM으로 자동 폴백
- 종류: Apple FM(온디바이스) / Ollama(로컬) / OpenAI 호환(원격). 모델 목록은 `설치된 모델 불러오기`(`/api/tags`)·`모델 목록 불러오기`(`/v1/models`)로 조회
- **예비 AI 폴백**(2026-10-21): `fallbackProviderID`("" = 사용 안 함) + `fallbackProvider`(주 모델과 같거나 비활성·미존재면 nil). 주 모델이 **429·5xx·빈 응답·키/요청 거부·시간 초과·연결 실패**로 실패하면 예비 모델로 **1회만** 재시도(`UIStore.streamReplyWithFallback`, 판정 `ProviderFallback.allowed`). **403(정책)·413/422(첨부 거부)·설정 오류는 전환하지 않는다**. 예비 예산이 더 작으면 `ConversationMemory.fitHistory`로 오래된 턴을 덜어내고, 첫 델타에서 `⚠️ 주 모델(X) … 예비 모델(Y)로 답했습니다 — <원인>` 안내를 붙인다(사슬 없음, `E-MAC-FALLBACK-0001/0002`)
- 실패는 목업으로 숨기지 않고 코드 표시: E-MAC-NET-0001(연결), E-MAC-NET-0002(미설정·모델 없음), E-MAC-KEY-0001(키 없음), **E-MAC-KEY-0002(서버가 키·접근 거부), E-MAC-NET-0003(업스트림 5xx·빈 응답), E-MAC-NET-0004(사용 제한 429), E-MAC-NET-0005(그 밖의 요청 거부)**

### 5.1 첨부 전송 규칙 (v0.13 수정 — **내용을 실제로 보낸다**)
- 대화 기록의 `Attachment`는 **이름·종류·원본 경로(`path`)** 를 남기고, 전송 순간 `AttachmentLoader`가 파일을 읽어 `OutgoingAttachment`로 만든다
  - **텍스트·코드 파일**: 본문을 프롬프트에 인라인(`[첨부 파일: 이름]` + 코드펜스). 10만 자 초과 시 잘라내고 안내
    - 지원 확장자(v0.13 핸드오프 P3): `md·markdown·txt·text·rtf·log·json·jsonl·csv·tsv·yml·yaml·xml·plist·toml·ini·cfg·conf·env·html·htm·css·scss·js·mjs·cjs·ts·tsx·jsx·swift·py·rb·go·rs·java·kt·kts·cs·php·c·h·cc·cpp·hpp·m·mm·sh·zsh·bash·sql·srt·vtt·tex·bib·patch·diff`
  - **PDF**: `PDFKit`으로 **텍스트 층만** 추출해 인라인(`PDF n쪽에서 텍스트만 뽑아 보냈습니다` 안내). 스캔본처럼 텍스트가 없으면 사유를 남긴다(무음 실패 금지)
  - **이미지**: `data:<mime>;base64,…` — OpenAI 호환은 `content` 파트 배열의 `image_url`, Ollama는 `images: [base64]`
  - 파일 IO·base64는 **메인 밖**(`Task.detached`)에서 수행
- 크기 상한: 이미지 data URL 5MB · 변 3000px(넘으면 2048→JPEG까지 단계적으로 줄임). 텍스트 10만 자
- **지원하지 않는 형식은 조용히 버리지 않는다**: 클립보드·파일 선택·QuickShelf 파일 탭에서 걸러낸 항목은 입력독 위 배너(`attachNotice`, QuickShelf는 자체 배너)로 "첨부할 수 없는 형식입니다: 이름" 안내(9초 후 자동 닫힘)
- **클립보드 파일은 경로를 보존한다**(핸드오프 P1): `ClipboardItem.fileURL` → `AttachmentLoader`가 본문을 읽는다. 항목 수명(2분) 중 파일이 사라졌거나 경로가 없으면 "이름만 전달됩니다"를 배너·`⚠️ 첨부 안내`로 알린다
- **전송 후 표시**: 보낸 말풍선에 첨부 카드가 붙는다 — 이미지는 썸네일(150×100, 해상도·용량 배지), 그 외는 아이콘+이름+크기. **호버하면 입력 전 칩과 같은 미리보기 카드**가 뜨고, 우클릭으로 `미리보기 열기`/`Finder에서 보기`. 원본이 지워졌으면 아이콘 카드 + `원본 파일이 없습니다`로 폴백

| 상태 | 의미 | 코드 | 재시도 |
|---|---|---|---|
| 400·422 (이미지 포함) | 모델이 첨부(이미지)를 못 받음 | `E-MAC-ATT-0003` | 텍스트만 |
| 400·422 (이미지 없음)·그 밖의 4xx | 요청 거부 | `E-MAC-NET-0005` | 없음 |
| 401·403 | 서버가 키/접근 거부 | `E-MAC-KEY-0002` | 없음 |
| 413 | 첨부 용량 초과 | `E-MAC-ATT-0002` | 이미지 더 작게(1400px JPEG) |

| 200 + 빈 본문 | 빈 응답 | `E-MAC-NET-0003` | 없음 |

  - 프록시가 주는 `error.code`(예: `E-AND-AUTH-0004`)를 파싱해 상태코드보다 우선한다(400으로 감싼 인증 실패도 401처럼 처리)
  - **응답 본문은 사용자 문구로 노출하지 않는다** — 서버 코드만 `[E-AND-…]`로 덧붙인다([HARD] 로그 마스킹)
  - **네트워크 오류는 정확한 원인으로 표시한다**(2026-10-20 → 2026-10-21 보강): `URLError`(연결 거부 -1004·시간 초과 -1001·오프라인 -1009·DNS -1006·TLS -1200)를 `AIErrorText`(Core)가 표시 언어 문구로 바꿔 말풍선에 `(오류 CODE) 원인 (host:port) (NSURLError n)`을, 상태 카드에는 `연결 거부 (-1004)` 한 줄을 붙인다. 서버 오류는 말풍선·연결 테스트에 `HTTP 상태 · 서버 코드`와 원인·다음 행동을, 상태 카드에는 `HTTP 503 · server_error — 모델 서버 과부하·점검·프록시 오류 가능. 잠시 후 재시도하거나 다른 모델을 선택하세요`처럼 **원인·상태·서버 코드·행동**을 2줄로 표시한다. `E-MAC-NET-0003`은 앱 네트워크 오류가 아니라 **모델/업스트림 5xx**다. 호스트는 host·port만 쓰고 경로·키는 노출하지 않는다
  - 사다리는 Core `AttachmentRetry`에 있어 단위 테스트로 고정된다
- 줄여 보냄·잘라냄·미전송 사유는 **답변 앞에 `⚠️ 첨부 안내`로 표시**(무음 실패 금지). Apple FM은 이미지를 받지 않으므로 텍스트만 보내고 그 사실을 알린다
- QA: `--ask=<질문> --attach=<경로>`(여러 번 가능) · 살아있는 검증 `QT_LIVE=1 swift test --filter LiveAttachmentCheck`(이미지 2케이스 + 잘못된 토큰이 `E-MAC-KEY-0002`로 분류되는지)
- **첨부가 실제로 실렸는지 판정**: 프록시는 설계상 요청 본문·프롬프트를 저장하지 않는다 → **프롬프트 토큰 델타**로 본다. 같은 질문을 ① 첨부 없이 ② 첨부해서 보낸 뒤 프록시의 `promptTokens`(기기 UI 로그 줄 `… · N tok` 또는 `/data/data/com.borasarang.zenfreeproxy/files/token-usage.json`)를 비교한다. 텍스트 파일이면 수천~수만, 이미지면 수백~수천 토큰 차이가 나야 하고 **델타≈0이면 내용이 안 실린 것**이다
- 원격 프록시(192.168.86.30:8791) 접속: 외부 공유가 켜져 있으면 `Authorization: Bearer <접속 토큰 zfp_…>`이 필수다(설정 > AI의 API 키 칸). 값이 틀리면 401 + 서버코드 `E-AND-AUTH-0004` → `E-MAC-KEY-0002`로 표시되고 **이미지를 빼고 재시도하지 않는다**(P2). 프록시 측 변경은 필요 없다(`stream:true` SSE·`image_url` data URL 통과, `read` 툴만 조건부 주입·제거). 스트리밍을 무시하고 JSON으로 답해도 앱이 폴백한다

### 5.2 대화 기억 정리 (T-71)
- **언제**: 요청 컨텍스트가 프로바이더 입력 예산의 **70%**를 넘으면, **답변 성공 후** 백그라운드 Task로 정리한다. 답변 중에는 절대 돌지 않는다.
- **무엇을**: 최근 원문 `compactKeepTurns`(기본 6, 짝수 보정, Apple FM은 4)를 남기고 그 이전 턴을 요약한다. 기존 요약이 있으면 새 구간만 합쳐 **롤링 요약**을 만든다.
- **전송**: `요약`은 턴이 아니라 **프롬프트 앞**에 고정하고, 기록에는 경계 이후 원문만 넣는다(Apple FM 6턴 제한에 요약이 잘리지 않게).
- **원문 불변**: `Conversation.summary`·`summaryThroughTurnID`만 갱신한다. 턴 삭제·이동 없음. 경계가 사라진 요약은 무시한다.
- **예산**: Apple FM 4,096(입력 2,816) / Ollama 기본 8,192 / 원격 기본 32,768. 프로바이더 편집의 `contextTokens`로 재정의.
- **수동**: `/compact`는 일반 UX가 아닌 보조 명령. 일시 중지도 해제하고 즉시 정리한다.
- **해제**: `[해제]`는 요약을 지우고 `compactPaused`로 자동 정리를 멈춘다. `[다시 켜기]`는 재개하며, 예산을 넘었으면 즉시 백그라운드 정리.
- **UI**: 입력독 위 배너(정리 중/요약됨/일시 중지/실패), [보기] 시트, 설정 › AI › 대화 기억 정리 카드.
- **로그**: 턴 수·요약 글자 수·지연만. 대화 내용·요약 본문은 남기지 않는다.
- 상세: `docs/plans/PLAN_v0.15_memory_macos.md`

### 8.0 창 레벨 · 대화 기록 (2026-10-20 개정 — 사용자 보고 3건)
- **기본은 일반 창 레벨**(`panel.level = .normal`). 이전에는 `isFloatingPanel = true`라 **항상** 다른 앱 위에 떠서 설정 창·시스템 설정·권한 안내가 뒤로 숨었다(사용자 보고: "대화창이 최상위인데 핀으로 한 거 아닌가?")
- **📌 = 항상 위 토글**(`settings.alwaysOnTop`, 기본 꺼짐) → 켜면 `.floating`. **대화 보관은 🔖(bookmark)로 분리** — 이전 📌가 "보관함에 저장"이라는 뜻이라 항상 위로 오해됐다
- 설정 창·정보 패널이 떠 있는 동안(`auxWindows`), 시스템 권한 안내가 진행되는 동안(`systemPromptDepth`)에는 📌가 켜져 있어도 **자동으로 일반 레벨로 내린다**(`applyPanelLevel`). 권한 경로: 화면 기록 `CGRequestScreenCaptureAccess`, 받아쓰기·마이크 `SFSpeechRecognizer.requestAuthorization`/`AVCaptureDevice.requestAccess`, 시스템 설정 딥링크 — `.quickTalkSystemPromptBegin/End` 알림으로 감싼다. 완료 콜백이 없으면 30초 뒤, 앱이 다시 활성화되면 즉시 복구
- **모든 대화를 자동 저장**(`PersistenceService`, `~/Library/Application Support/QuickTalk/history.json`): 이전에는 핀한 대화만 `pinned.json`에 남고 나머지는 앱을 끄면 사라져 "대화가 하나도 기록되지 않는다"는 보고로 개정. 미보관 대화는 `keepDays`(기본 30일) 뒤 정리, 🔖 보관분은 나이 무관. 구버전 `pinned.json`은 첫 로드에서 승계. 정리·정렬 규칙은 `ConversationHistory`(순수 함수·테스트 대상): 보관 우선 → 최근 갱신 순
- 앱 시작 시 **마지막 대화를 이어서 연다**(`restoreLastConversation`). 설정 `단축키로 열 때 새 대화`(기본 **꺼짐**)를 켜면 예전처럼 열 때마다 새로 시작. 구버전 기본값(true)은 `QuickTalk.migrate.autoHistory.v1` 1회 마이그레이션으로 끈다
- ✎(새 대화)·대화 전환·전송·응답 시 **현재 대화를 먼저 기록에 반영**한다(휘발 금지). 보관함 탭 = "진행 중 + 대화 기록(날짜·턴·보관 여부)" 목록, 삭제는 **자체 확인 시트**를 거친다 — 제목과 `N개 턴`을 보여 주고 **취소가 기본(Esc)**, 빨간 **[삭제]**를 눌러야 실행되며 Enter로는 실행되지 않는다. 설정 › 보관함의 **[기록 모두 지우기]**도 같은 확인을 쓴다.
- **대화방 제목 = 첫 질문에서 자동 생성** — 줄바꿈·연속 공백을 한 칸으로 접고 30자에서 말줄임(`Conversation.autoTitle`). 첫 질문에서만 만들고 이후 질문은 건드리지 않는다. 사용자가 직접 바꾼 제목(`titleEdited`)은 자동 생성이 절대 덮지 않는다. 화면은 `displayTitle`(사용자 제목 > 저장 제목 > 첫 질문 > "새 대화")을 쓰고, 구버전 기록의 "새 대화" 제목은 불러올 때 첫 질문으로 채운다(`ConversationHistory.normalized`). 변경은 **대화 헤더 제목 클릭**(호버 시 밑줄) 또는 **보관함 행 [변경]** → 공용 `RenameSheet`(Enter 저장 · Esc 취소 · 빈 제목 거부 · 여러 줄은 한 줄로 접기). 제목 변경은 `updatedAt`을 바꾸지 않아 보관함 정렬이 튀지 않는다.
- **보관함 검색 결과를 열면 그 대화의 맨 아래가 아니라 검색어와 처음 일치하는 턴으로 간다** — 질문·응답 어느 쪽이든 대소문자 무시(`Conversation.firstTurn(matching:)`). 그 턴을 화면 중앙에 놓고 **보라 테두리를 3회 깜빡**여 위치를 알린다(`SearchFocusRequest`, 같은 결과를 다시 눌러도 다시 깜빡). 탭 전환 직후 레이아웃 전 스크롤은 4회 보정하고, 포커스가 살아 있는 동안은 바닥 자동 스크롤을 하지 않는다. 제목만 일치하거나 검색어가 비면 기존처럼 맨 아래
- 창이 보이지만 다른 앱 뒤에 있으면 단축키가 **닫지 않고 앞으로** 가져온다(`togglePanel`의 frontmost 판정). QuickShelf 결과 표시(`showChatFromShelf`)도 앞으로 올린 뒤 탭만 전환

### 8.3 QuickShelf — Edge 허브 (v0.13 개정: **창 안 엣지 패널**)
- **이름: QuickShelf(퀵셸프)**. 같은 뷰(`ShelfView`)를 **놓이는 자리만 바꿔** 쓴다(단일 출처)
- **기본 위치 = 대화창 안 오버레이**(목업 v0.6 §3 `.panel{position:absolute; right:0; top:8px; bottom:8px; width:300px}`): 대화창 헤더의 QuickShelf 버튼(또는 `⇧⌥V`) → **창 크기는 그대로** 두고 오른쪽 위에 폭 300pt 카드가 **겹쳐 뜬다**(가장자리 여백 8pt·모서리 12pt·왼쪽 그림자). 뒤 대화는 scrim(검정 28%)으로 살짝 눌러 주고, **바깥 클릭·Esc·✕**로 닫는다. 창을 닫으면 상태만 남고 다시 열면 그대로 떠 있다
  - **창 폭을 늘리지 않는다** — 이전 구현(`resizeForShelfDock`, +301pt)은 목업과 달라 제거했다. 창 폭 저장값도 건드리지 않는다
  - 도킹 중 키: `Esc`=닫기, `⌘O`=파일 추가, `⌘⇧O`=이미지 추가 (오버레이는 별도 창이 아니므로 `ShelfController`의 로컬 키 모니터가 **도킹 상태일 때만** 받는다)
  - 호버 미리보기는 패널 **왼쪽**에 뜬다(`ShelfMetrics`: 폭 300 · 여백 8 · 미리보기 간격 12)
- **보조 위치 = 화면 가장자리 패널**: 대화창이 닫혀 있을 때만. **화면 가장자리 핸들은 2026-10-21 제거** — `⇧⌥V` 또는 헤더 버튼으로 연다. 열리면 모든 앱 위에 `NSPanel`(폭 300pt)이 뜬다
- 패널은 `.statusBar` 레벨 borderless 창(모든 Space)으로 **포커스는 뺏지 않는다**. 두 위치가 동시에 보이지 않는다(도킹이 켜지면 플로팅 패널은 접힌다)
- 창 폭은 바꾸지 않는다 — 허브는 **창 안 오버레이**(§8.3). 도킹은 창 크기·위치 자동 저장에 영향을 주지 않는다
- 캡처 순간에는 플로팅 패널·대화창(도킹 포함)을 잠깐 내려 우리 UI가 찍히지 않게 하고, 캡처가 끝나면 "보고 있는 자리"(창이 떠 있으면 도킹, 아니면 가장자리)에 허브를 연다
- 탭 3개: **클립보드 / 파일·이미지 / 캡처** — 모두 같은 카드 문법(썸네일·남은시간·호버 미리보기·클릭 사용). **대화에 첨부로 사용한 카드는 목록에서 사라진다** — 파일은 원본을 그대로 두고 카드만 제거, 캡처는 `QuickTalk/clip`에 임시 복사한 뒤 원본 캡처 파일과 카드를 함께 지운다(첨부가 삭제된 경로를 가리키지 않게).
- 캡처: **전체화면(`⌥⇧3`) · 윈도우(`⌥⇧⌘4`) · 드래그 선택(`⌥⇧4`)** — 세 조합 모두 설정 › 단축키에서 바꿀 수 있다(§9). ScreenCaptureKit + 자체 오버레이(크기·힌트·윈도우 강조·Esc·십자 커서). 오버레이 안에서 **Space = 드래그 ↔ 윈도우 모드 전환**(macOS 기본 캡처와 같은 동작) — 어느 모드로 열었든 Space로 오간다. 마우스를 떼면 바로 허브에 쌓이고, **캡처 카드에 호버하면 복사·다른 이름으로 저장·Finder 툴바**가 뜬다(카드 클릭은 대화 첨부, **첨부하면 카드는 목록에서 사라짐**).
  - **윈도우 캡처는 화면을 자르지 않는다** — `SCContentFilter(desktopIndependentWindow:)`로 **그 창의 표면만** 다시 떠서, 위에 겹친 다른 창·바탕화면이 찍히지 않는다(그림자는 `ignoreShadowsSingleWindow`로 제외). 창이 닫혔으면 `E-MAC-CAP-0002` + "창이 닫혔거나 최소화되었는지" 안내
  - **좌표계는 `CaptureGeometry` 한 곳에서만 변환한다**(순수 함수·테스트 고정): `CGWindowList`(좌상단 원점) → AppKit 전역(좌하단 원점) → 오버레이 로컬 → 이미지 픽셀(좌상단 원점). 섞으면 엉뚱한 창이 강조·선택된다(2026-10-20 실측 버그)
  - 윈도우 강조 라벨에는 **앱 이름**을 띄워 어느 창을 잡았는지 확인할 수 있게 한다
  - `⌘⇧3/4`는 시스템 전용이라 **앱이 가로채지 않는다**. 자체 단축키만 제공
  - 캡처 결과는 **첨부하거나 직접 삭제할 때까지** 유지된다. 복사·다른 이름으로 저장은 카드를 없애지 않는다(클립보드의 2분 정책과 다름)
- 설정: 캡처를 클립보드에도 복사 / 열기 단축키 표시 / 화면 기록 권한 / 저장 폴더·보관 정책 (가장자리 핸들 토글은 제거)


### 8.2 응답 대기 표시 + 전송 상태 (v0.12 개정, 사용자 요청)
- 전송 직후 입력창을 즉시 비우고, 대화 영역 왼쪽에 **"응답 중…" 자체 점 애니메이션**(`TypingDots`) + `프로바이더 · 모델 · N초`(0.5초 틱) 표시
- 응답 대기 중에는 입력독의 `↑`가 `…`(비활성)로 바뀌고, `send()`도 중복 전송을 무시한다(답이 섞이지 않게). 입력창 자체는 계속 타이핑 가능
- 새 턴·대기 상태 변화 시 대화 영역이 **자동으로 맨 아래로 스크롤**(`ScrollViewReader`, 긴 대화에서 답이 화면 밖에 생기는 문제 방지)
- 전송 경로를 `onCommit`(구형) → `onSubmit`으로 교체하고, **전송 직후 0.5초간 같은 텍스트가 되돌아오면 입력창을 다시 비우는 방어**(`suppressEcho`)를 추가 — 한글 IME 조합 커밋이 입력창에 남는 문제 대응
- QA: `--ask=<질문>` 으로 실행하면 창을 띄우고 실제로 1회 전송한다(응답 중 표시·전송 E2E 확인용)

### 8.2.1 스트리밍 응답 (2026-10-20, 사용자 요청)
- **응답을 다 받은 뒤 한 번에 그리지 않는다** — 토큰이 도착하는 대로 말풍선에 이어 붙인다
  - OpenAI 호환: `stream:true` + **SSE**(`data: {"choices":[{"delta":{"content":"…"}}]}`, `data: [DONE]`)
  - Ollama: `stream:true` + **NDJSON**(`{"message":{"content":"…"},"done":false}`, `{"done":true}`)
  - Apple FM(FoundationModels): 스트리밍 API를 쓰지 않고 한 번에 전달(이미지 제외 안내는 먼저). 다른 경로와 UI는 동일
- 전송은 `URLSession.bytes(for:)` → `bytes.lines`. **Content-Type이 `text/event-stream`/`x-ndjson`이 아니면** 본문을 모아 일반 JSON으로 디코드하고(본문이 `data:`면 SSE로 파싱), 스트리밍 형식인데 델타가 없으면 **비스트리밍 1회 폴백**(프록시가 스트리밍을 흉내만 내는 경우)
- **부분 출력 규칙**: 델타가 한 글자라도 나간 뒤에는 첨부 재시도 사다리를 타지 않는다(글자 중복 방지). 재시도 응답은 원인 안내(`⚠️ …`)와 함께 한 번에 전달. 실패하면 지금까지의 글자를 **지우지 않고** 원인 문구를 아래에 덧붙인다
- **UI**: 빈 어시스턴트 턴을 먼저 만들고 델타를 **80ms 스로틀**(초당 12회)로 반영 — 마크다운 재파싱 부담 완화. 첫 글자가 오면 "응답 중…" 점 표시를 숨긴다. 글자 수가 늘 때마다 `followStream`이 **애니메이션 없이 한 번** 바닥으로 스크롤(검색 포커스 중에는 끌지 않음). 완료 시에만 `history.json` 저장 + 응답 시간 기록
- **질문 중복 금지**: 스트리밍 턴을 붙이기 전에 `history`(이번 사용자 턴 제외)를 잡아 둔다 — 붙인 뒤 `dropLast()`를 하면 이번 질문이 두 번 들어간다
- QA: `--demo-chat --demo-stream`(부분 출력·점 숨김 렌더), `QT_LIVE_STREAM=1 swift test --filter LiveStreamTests`(로컬 SSE/NDJSON 서버로 실제 HTTP 스트리밍 검증)

## 9. 키 입력 정책 (v0.10 수정, 2026-10-20 전역 단축키 5종으로 확장)
- **전역 단축키는 앱이 쓰는 것 전부를 설정에서 바꿀 수 있다**(`ShortcutAction` — Core):

  | 동작 | 기본 | 설명 |
  |---|---|---|
  | 대화 열기 | `⌘Space` | 어디서든 대화 창 열기/닫기 |
  | 퀵셸프 열기/닫기 | `⇧⌥V` | 클립보드·파일·캡처 허브 (⌥⌘V는 다른 앱의 '경로 복사'와 겹쳐 기본값을 옮김) |
  | 캡처 — 전체 화면 | `⌥⇧3` | 모든 화면 |
  | 캡처 — 드래그 선택 | `⌥⇧4` | 드래그한 영역 |
  | 캡처 — 윈도우 | `⌥⇧⌘4` | 클릭한 창만 |

  - 조합은 `ShortcutCombo`(Core)가 **정규화·표시·검증**한다. 저장은 `"Option+Shift+3"` 같은 토큰 문자열, 화면은 `⌥⇧3` 기호. `⌥⇧3`·`opt+shift+3`·`⌘Space` 같은 표기도 파싱한다.
  - **보조 키 없는 단일 키는 전역 단축키로 쓰지 않는다**(오타·시스템 키 충돌 방지). 키는 A–Z·0–9·Space·Return·Tab·Esc·화살표·F1–F12·문장부호.
  - 설정 › 단축키의 각 행에서 **변경 → 원하는 조합 입력**(로컬 keyDown 모니터), **Esc 취소 · Delete = 기본값**. 같은 조합을 다른 동작이 쓰고 있으면 즉시 안내하고 저장하지 않는다(`shortcutConflict`).
  - 녹화 중에는 **등록된 전역 핫키를 잠시 해제**한다(`.quickTalkSuspendShortcuts`) — 이미 등록된 조합을 눌러도 그 동작이 실행되지 않고 설정 창이 키를 받는다. 녹화가 끝나면(취소·저장·창 닫힘) 다시 등록(`.quickTalkResumeShortcuts`).
  - 등록은 `AppDelegate.applyShortcuts`가 **동작별 Carbon 핫키**로 하고, 조합이 바뀐 것만 해제→재등록한다. 실패한 동작은 설정 행에 ⚠️(`store.shortcutStatus`) + `E-MAC-KEY-0001` 로그.
  - `NSEvent` 전역 모니터는 **입력 모니터링 권한**이 없으면 조용히 실패하므로 전역은 Carbon `RegisterEventHotKey`만 쓴다(권한 불필요, Spotlight 기본값과 같은 조합도 앱 등록이 우선).
- 편집 단축키(⌘C/⌘V/⌘X/⌘A/⌘Z/⌘⇧Z): 이 앱은 `LSUIElement`(메뉴바 전용, 메뉴바 없음)라 ⌘ 키 등가가 macOS 정책상 불안정하게만 전달된다
  → **우리 창이 키일 때만** Carbon으로 일시 등록하고, 창이 키를 잃으면 즉시 해제한다(다른 앱 단축키를 점유하지 않음)
  → 보조로 로컬 키 모니터가 있으며, 문자 대신 **키코드**로 비교한다(한글 입력 소스에서 `charactersIgnoringModifiers`가 'ㅍ'처럼 변한다)
- 진단 플래그: `--debug-keys`(⌘ 키 수신 로그), `--no-edit-hotkeys`(Carbon 편집 단축키 끄기)

## 10. 음성 — Whisper 로컬 (v0.13 개정: **두 백엔드 모두 지원**)
- 받아쓰기 엔진은 2종: **Apple 음성인식**(즉시) / **Whisper 로컬**. Whisper는 백엔드를 다시 3가지로 고른다 — **자동(설치된 것 우선) / mlx-whisper(Apple GPU, 정확) / whisper.cpp(CPU, 가벼움)**
  - 자동은 `mlx-whisper` → `whisper.cpp` 순으로 **준비된 것**을 쓴다. 둘 다 있으면 mlx-whisper
  - 바이너리 탐색: 절대 경로 후보(`~/.venvs/mlx-whisper/bin/mlx_whisper` · `/opt/homebrew/bin/mlx_whisper` · `whisper-cli` 등) → PATH. **Finder 실행 시 PATH가 최소**라 `/usr/bin/env` + 보강 PATH(`/opt/homebrew/bin`, `~/.local/bin`, venv)로 실행한다(ffmpeg·python을 못 찾는 문제 방지)
  - **언어 선택**: Apple 쪽은 `appleSpeechLocale`(시스템 `SFSpeechRecognizer.supportedLocales()` 62종 중 선택, `""`=한국어 우선), Whisper 쪽은 `whisperLanguage`(자동/ko/en/ja/zh/es/fr/de)로 **따로** 둔다. Apple 언어를 바꾸면 인식기를 다시 만들고, 지원하지 않는 코드면 한국어→영어로 폴백하고 로그를 남긴다
  - **읽어주기(TTS)도 선택 가능**: `ttsLanguage`(설치된 목소리가 있는 언어만) · `ttsVoiceID` · `ttsRate`(0.35~0.62, 기본 0.48). 목록은 `SpeechCatalog`(순수 함수·테스트 대상)가 **품질 프리미엄→향상→기본→저품질** 순으로 만들고, 같은 목소리의 `compact`/`super-compact` 중복은 좋은 쪽만 남긴다. `ttsVoiceID`가 비어 있으면("자동") 그 언어에서 **가장 좋은 품질**(예: 한국어 = Siri 자연스러운 Minji → 향상)을 고른다 — 기본 읽어주기 소리가 로봇 같던 문제 해결. 설정 창에 **미리 듣기** 버튼
- **읽어주기 엔진 3종**(2026-10-20, T-58·T-60): `ttsEngine` = `apple`(`AVSpeechSynthesizer`, 오프라인) / `edge`(Microsoft Edge 신경망 음성, 온라인). Edge는 `edge-tts` CLI를 **프로세스로 실행**해 mp3를 임시 폴더에 받고 `AVAudioPlayer`로 재생한다(`QuickTalkApp/EdgeSpeechService.swift`) — 합성 중에도 중지할 수 있게 `isSpeaking`을 즉시 켜고, `stop()`은 실행 중 프로세스를 종료한 뒤 임시 파일을 지운다. 실행 파일은 `edgeBinaryPath`(직접 지정) → `~/.venvs/edge-tts/bin` → `~/.local/bin` → Homebrew → `/usr/local/bin` 순(Finder 실행은 PATH가 최소라 절대 경로 탐색). 목소리는 `EdgeTTS.voices`(한·영·일·중 13종) + ID 직접 입력, 속도는 Apple 슬라이더(0.35~0.62)를 `-50%~+55%`로 환산해 `--rate`에 넘긴다. 실패는 `E-MAC-AUDIO-0002`로 로그·설정 '최근 오류'에 남기고, 세 엔진의 재생 상태는 `UIStore.isSpeaking` 하나로 합쳐 헤더·말풍선 ⏹이 일관되게 동작한다.
- **Piper 로컬 음성**(2026-10-20, T-60): `ttsEngine = piper` — `piper` CLI를 프로세스로 실행해 **WAV**를 임시 폴더에 만들고 `AVAudioPlayer`로 재생한다(`QuickTalkApp/PiperSpeechService.swift`). 텍스트는 인자 길이 제한을 피해 임시 `.txt`로 넘기고(`-i`), 모델은 `-m`, 같은 이름의 `.onnx.json`이 있으면 `-c`로 함께 넘긴다. 모델은 `piperModelPath`(파일 또는 폴더) → `~/Documents/Files/piper-ko-eva` → `~/Documents/Files/piper` → `~/Library/Application Support/QuickTalk/piper` → `~/.local/share/piper` 순으로 찾고, 실행 파일은 `~/.venvs/piper/bin` → `~/.local/bin` → Homebrew → `/usr/local/bin`. 속도는 Apple 슬라이더를 `--length-scale`로 환산한다(클수록 느림 → `0.48 / rate`, 0.70~1.45 클램프, 0.48 = ×1.00). 실패는 `E-MAC-AUDIO-0003`. 설치: `python3 -m venv ~/.venvs/piper && ~/.venvs/piper/bin/pip install piper-tts`.
- 모델은 **형식이 다르다**: whisper.cpp = `ggml-*.bin` 파일 / mlx-whisper = `config.json` + 가중치(`.safetensors`/`.npz`) 폴더
  - 검색 폴더: 설정한 폴더 → `~/Documents/Files/whisper` → `~/Library/Application Support/QuickTalk/models` (중첩 1단계까지)
  - 자동 선택 규칙: **폴더 우선순위 → 같은 폴더 안에서 큰 모델 먼저**(품질 우선 — 예: large-v3-turbo > base). 설정에서 직접 지정하면 그것이 최우선
  - 설정 화면은 감지된 모델을 자체 목록으로 보여주고(드롭다운) 경로 직접 지정도 허용한다
- **언어 설정(기본 한국어)**: 짧은 음성에서 자동 감지가 영어로 새는 문제가 있어 기본 `ko`. whisper.cpp `-l ko` · mlx `--language ko`. "자동 감지"로 바꿀 수 있다
- 실행: whisper.cpp = `-m <bin> -f <wav> -nt -np -l <lang>` / mlx = `--model <dir> --output-format txt --output-dir <tmp> --verbose False --language <lang> <wav>` → 결과 txt를 읽고 임시 폴더를 지운다
- 프로세스 실행은 메인 밖(`DispatchQueue.global`)에서, stdout/stderr를 **동시에** 읽어 파이프가 차서 멈추는 문제를 막는다. 실패는 `E-MAC-AUDIO-0001` + 상태 문구(백엔드 이름 포함)
- QA: `QT_LIVE_WHISPER=<wav> swift test --filter LiveWhisperCheck` — 두 백엔드로 같은 파일을 전사해 결과·소요 시간을 출력
