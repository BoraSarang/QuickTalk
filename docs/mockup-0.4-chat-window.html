2. 스트립 상세 동작 텍스트 / 이미지 / 만료 / 민감 항목

2 · 항목별 표현과 클릭 동작
방금 복사 아아아아아아아아…✕ 스크린샷 20.41.07✕ URLhttps://example.com/a…✕ MDreport.md · 2KB✕ 민감•••••••• 0:58
텍스트 — 1줄 미리보기(말줄임). 클릭 → 입력창에 삽입(커서 위치)
이미지 — 26pt 썸네일. 클릭 → 첨부로 추가
만료 — 복사 시점부터 1~2분, 남은 시간 표시. 지나면 자동 제거
민감 항목 — 비밀번호 관리자/토큰 추정 시 흐리게(내용 비표시), 눌러야 표시
✕ — 그 항목만 지움(클립보드 자체는 건드리지 않음)
최대 개수 — 최근 N개(예: 5개). 넘치면 오래된 것부터 사라짐

텍스트는 삽입, 이미지·파일은 첨부로 동작이 다릅니다. 민감 항목은 규칙([HARD] 로그·화면 노출 금지)에 맞춰 기본 마스킹을 제안합니다.

4. 창 크기 정책 고정 vs 가변 — 가변이면 탭은 어떻게

정책동작보관함 탭설정 탭스트립 영향
① 고정 유지
460×560		 지금처럼 내용 크기 고정. 리사이즈 잠금(불필요한 리사이즈로 깨지는 일 없음) 고정 크기 안에서 스크롤 공유 카드가 560에 맞춰짐(현재 여백 ~120pt) 세로 38pt를 항상 본문에서 빼앗음
② 가변 (추천)
최소 420×420 · 자유 리사이즈 · 크기 기억		 본문이 늘고 줄어듦. 입력독·스트립은 하단 고정. 3개 탭 모두 같은 창 안에서 늘어남 목록이 길어지면 그대로 더 보임(스크롤 유지) 설정 카드가 위로 몰리고 아래 여백 → 카드 폭 제한(예: 최대 520pt 중앙 정렬) 공간이 늘면 스트립이 부담 없음
③ 컴팩트 → 확장
380×150 pill로 시작		 포인터 옆에서 작게 시작(참고 2번째 이미지) → 질문을 보내면 460×560으로 확장 확장 후 ②와 동일 확장 후 ②와 동일 pill 상태에서는 스트립 1줄만(입력 위)
