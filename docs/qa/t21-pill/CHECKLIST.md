# T-21 포인터 pill — 사용자 실측 체크리스트

> 빌드: 2026-10-21 20:3x (재실행 필요) · macOS · 한/영 모두 확인
> 렌더 참고: `docs/qa/t21-pill/`, `docs/qa/t21-pill-light/`

## A. 표시 조건

| ID | 절차 | 기대 |
|---|---|---|
| P1 | 마지막 질문 후 **10분 초과** → ⌘Space | 포인터 자리에 **pill만** 뜬다. **빈 대화 창은 뜨지 않는다** |
| P2 | pill을 Esc로 닫고 다시 ⌘Space (아직 10분 초과) | 다시 pill. 기록이 새로 생기지 않는다(보관함 개수 그대로) |
| P3 | 대화 1턴 후 **10분 이내** ⌘Space | 지금처럼 **대화 창**이 뜬다(pill 아님) |
| P4 | 설정 › 일반 › “단축키로 열 때 유지” = **사용 안 함(0)** → ⌘Space | **항상 pill** |
| P5 | 앱을 새로 켜고(이어할 대화 있음) ⌘Space | 10분 이내면 대화 창, 지났으면 pill |

## B. 입력·전환

| ID | 절차 | 기대 |
|---|---|---|
| P6 | pill에 한글 입력 중 Enter | 조합이 확정되고 **그 질문이 전송**된다. 글자가 pill/입력창에 남지 않는다 |
| P7 | pill에서 Enter | pill이 즉시 사라지고 대화 창이 열리며 응답이 스트리밍된다 |
| P8 | pill에 글자 입력 → **⌘Return** | 전송하지 않고 대화 창이 열린다. 입력한 글은 **초안으로** 남는다 |
| P9 | pill에서 **Esc** | pill만 닫힌다. 대화 기록·마지막 대화 상태 그대로 |
| P10 | pill이 뜬 상태에서 ⌘Space | pill이 닫힌다(토글) |
| P11 | 다른 앱을 클릭 | pill이 닫힌다(포커스 이동). 그 앱은 그대로 활성 |
| P12 | 다른 앱에서 ⌘Space → Esc | 직전 앱으로 포커스가 돌아온다 |
| P13 | 화면 가장자리(모서리)에서 ⌘Space | pill이 화면 밖으로 나가지 않는다 |
| P14 | 보조 모니터에서 ⌘Space | 포인터가 있는 화면에 뜬다 |

## C. 보관함 목록

| ID | 절차 | 기대 |
|---|---|---|
| P15 | pill의 보관함 아이콘 클릭 | pill 아래로 **최근 대화 최대 4개** 목록이 열린다(제목·상대 시간) |
| P16 | 목록에서 대화 1개 클릭 | 그 대화가 열리고 이어서 쓸 수 있다(1클릭) |
| P17 | 목록에서 **보관함 전체 열기**(또는 ⌘L) | 대화 창의 **보관함 탭**이 열린다 |
| P18 | 기록이 하나도 없을 때 목록 | `아직 대화가 없습니다` + 보관함 전체 열기 |
| P19 | 목록을 연 채 Esc | pill과 목록이 함께 닫힌다 |
| P20 | 목록이 화면 아래로 넘칠 위치 | 창이 위로 밀려 목록이 화면 안에 보인다 |

## D. 시각

| ID | 절차 | 기대 |
|---|---|---|
| P21 | 다크 / 라이트 | 캡슐·글자·아이콘 대비가 읽힌다. 좌우 끝에 **세로 이음새 없음** |
| P22 | 영어 모드 | `Ask anything` · `Open archive` · 목록 상대 시간이 영어 |
| P23 | 입력이 길 때 | 한 줄 안에서 가로로 스크롤(창이 커지지 않음) |
| P24 | 보관함 아이콘 호버 | 툴팁 `보관함 — 최근 대화 이어가기`, 아이콘 배경 강조 |

## E. 회귀

| ID | 절차 | 기대 |
|---|---|---|
| P25 | pill에서 질문 → 응답 중 ⏹ | 기존 중지 동작 그대로 |
| P26 | pill 없이 대화 창에서 새 대화·첨부·웹 검색 | 기존과 동일 |
| P27 | 메뉴바 Hub › 새 대화 / 보관함 열기 | 기존과 동일(pill 개입 없음) |
