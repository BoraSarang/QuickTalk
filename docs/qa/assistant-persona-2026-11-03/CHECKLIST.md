> 앱이 실행 중일 때만 예약 작업이 돈다. 알림은 앱이 켜져 있을 때만 온다(Phase 1 한계).

## 0. 준비 (한 번만)

- [ ] **앱 재실행** — 새 빌드를 배포한 뒤 메뉴바 QuickTalk → 종료 → 다시 실행.
- [ ] 설정 › AI — **원격 모델**(OpenAI 호환 등 도구 지원 모델) 선택. Apple FM 은 도구를 쓰지 않는다.
- [ ] 설정 › 도구·권한 — **도우미 도구 사용** 켜기.
- [ ] 설정 › 비서 — 비서 **2명**(예: 돌쇠·졸쇠) 만들기. 말투를 서로 다르게.
- [ ] 설정 › 비서 — **리포트 폴더**를 `~/Documents/Reports` 등으로 확인.
- [ ] 설정 › 비서 — **예약 작업 실행**·**완료 알림**·**승인 대기 알림** 켜기.
- [ ] 알림 권한이 `알림 권한이 허용되어 있습니다.` 인지 확인. 아니면 `[알림 허용]`.

## S1 — 비서 전환 · 말투

**하기**
1. 헤더의 비서 칩에서 **돌쇠**를 고른다.
2. "오늘 기분 어때?" 전송.
3. 같은 질문을 **졸쇠**로 바꿔 전송.

**기대**
- 헤더 칩에 지금 비서 이름이 보인다.
- 두 답변의 말투가 실제로 다르다.
- 목록 맨 위 `기본(비서 없음)` 을 고르면 **지금과 같은** 답변 스타일로 돌아간다.

## S2 — `/할일` · 1분 뒤 실행 · 리포트 파일

**하기**
1. 입력창에 `/할일` → 목록 시트가 열리는지 확인.
2. `[새 일정]` → 제목 `테스트 뉴스`, 지시문 `오늘의 테크 소식을 3줄로 요약해 줘`,
   반복 `한 번`, 실행 시각 **1~2분 뒤**, 비서 `돌쇠`, 사용 켜기 → 저장.
3. 시각이 되면 대화(보관함의 `🗓 돌쇠 · 테스트 뉴스`)를 연다.

**기대**
- 정시에 실행되고, 대화에 **성공 카드 + 핵심 요약 + 파일 경로**가 남는다.
- 설정한 리포트 폴더에 **Markdown 파일**이 생긴다. 파일을 열면 제목·시각·지시·본문이 있다.
- 완료 알림(배너 + 기본음)이 온다. 알림을 누르면 그 대화가 열린다.
- `/할일` 목록에 상태 `완료`, 다음 실행 없음(한 번짜리)이 보인다.

결과:

## S3 — 승인 대기 → 승인 → 이어서 완료

**하기**
1. `/할일` → `한 번`, 1~2분 뒤, 지시문: `바탕화면에 quicktalk-test.txt 파일을 만들고 'ok'라고 써 줘`.
2. 시각이 되면 기다린다. **승인 대기 알림**이 오면 눌러 대화를 연다.
3. 카드에서 `[승인]`.

**기대**
- 승인 전에는 파일이 만들어지지 않는다.
- 알림 문구에 **비서 이름 · 일정 제목 · 왜 승인이 필요한지**가 보인다. 알림에는 **승인 버튼이 없다**.
- 승인하면 그 지점부터 이어서 실행되고, 완료 카드·리포트가 남는다.
- 감사 로그에 `task:<id 앞 8자>` 태그가 붙는다(설정 › 기록).

결과:

## S4 — 승인 거부

**하기**
- S3 과 같은 일정을 다시 만들고, 승인 카드에서 `[거부]`.

**기대**
- 파일이 생기지 않는다.
- 카드에 **실패 + 사유**가 남고, 완료 알림이 `실패`로 온다.
- 다음 정시에 자동 재시도하지 않는다.

결과:

## S5 — 앱 종료 후 따라잡기

**하기**
1. 매일 일정(예: 5분 뒤)을 만든다.
2. 앱을 **종료**하고 예약 시각을 넘긴다(10분 정도).
3. 앱을 다시 실행한다.

**기대**
- 최근 **24시간** 안에 놓친 작업 **1회**가 실행된다. 중복 실행은 없다.
- 24시간이 넘었으면 실행하지 않고 `건너뜀` 으로 기록된다.
- 앱이 꺼져 있는 동안에는 알림이 오지 않는다(Phase 1 한계).

결과:

## S6 — 대화에서 일정 만들기 (`schedule_task`)

**하기**
- 대화에서 "이거 매일 오전 10시에 돌쇠가 실행하게 해 줘" 라고 말한다.

**기대**
- 모델이 **확인 카드**(제목·시각·지시문 전문·비서)를 띄운다.
- `[등록]` 전에는 `/할일` 목록에 없다. `[등록]` 후에만 생긴다.
- 같은 제목·규칙이 이미 있으면 `같은 일정이 있어 덮어씁니다` 가 보인다.
- 모델이 일정을 **삭제하는 도구는 없다** — 삭제는 `/할일` 에서만.

결과:

- **지난 리포트 파일은 남는다.**

## S8 — 알림 권한 거부

**하기**
1. 시스템 설정 › 알림 › QuickTalk → **알림 허용 끄기**.
2. 앱을 다시 실행하고 설정 › 비서를 연다.
3. 예약 작업을 한 번 실행한다.

**기대**
- 예약 실행은 **정상 동작**하고 리포트도 만들어진다.
- 설정 › 비서에 **"알림이 시스템 설정에서 꺼져 있습니다…"** 안내와 `[시스템 설정 열기]` 가 보인다.
- 알림은 오지 않는다.

결과:

## N1 — 야간 무음

**하기**
1. 설정 › 비서 › 야간 무음 켜기, 시간을 **지금부터 5분 뒤 ~ 10분 뒤**로 잠깐 바꾼다.
2. 그 사이에 한 번짜리 일정을 실행한다.

**기대**
- 배너는 뜨지만 **소리는 나지 않는다**.
- 무음 시간이 끝난 뒤 실행한 일정은 **소리가 난다**.

## N2 — 승인 대기 만료 (10분)

**하기**
- 승인이 필요한 일정을 실행하고, 카드에서 아무것도 누르지 않고 10분을 기다린다.

**기대**
- 10분 뒤 **실패(승인 대기 만료)** 로 기록되고 알림이 온다.
- 문구: `승인 대기 만료` · `10분 안에 승인하지 않아 취소되었습니다. 다시 실행하세요.`
- 승인 전이므로 파일·부작용은 없다.
