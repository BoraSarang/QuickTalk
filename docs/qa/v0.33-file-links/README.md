## 2. 사용자 실측 체크리스트

### P — ⌘Space pill = 쌩 새 대화

- [ ] **P1** 지난 대화가 있는 상태에서 세션 유지 시간이 지난 뒤 ⌘Space → pill → **Enter**(질문 입력) = 새 대화에서 시작하고 이전 턴이 보이지 않는다.
- [ ] **P2** pill 에서 비서(예: 테크충)를 고른 뒤 전송 = **새 대화**이고 그 비서만 적용된다. 설정의 기본 비서는 적용되지 않는다.
- [ ] **P3** pill 을 열었을 때 비서 버튼에 지난 대화의 비서 체크가 **없다**(`비서 없음`).
- [ ] **P4** pill 이 뜬 뒤 시간이 지나거나 다른 조작을 해도 전송은 항상 새 대화다.
- [ ] **P5** pill 목록에서 최근 대화를 직접 고르면 그 대화가 열린다(명시적 이어가기).

### F — 파일·폴더 열기

- [ ] **F1** 답변에 `/Users/…/QuickTalkReport/` 같은 **폴더 경로** → 클릭 = 파인더가 그 폴더를 연다.
- [ ] **F2** 답변에 `보고서.md` 처럼 **파일명만** 나열(같은 답변에 폴더 경로가 먼저 있음) → 클릭 = 기본 앱으로 열린다.
- [ ] **F3** 인라인 코드(`` `…/file.md` ``)도 모노 글꼴 그대로 클릭된다.
- [ ] **F4** `.command` · `.app` · `.sh` · `.pkg` · `.dmg` · 실행 권한 파일 클릭 = **확인 창** → `열기` 를 눌러야 실행된다.
- [ ] **F5** 존재하지 않는 파일명은 링크로 보이지 않는다(밑줄·보라색 없음).

- [ ] **C2** 누른 뒤 1.4초 동안 `복사됨` 으로 바뀌었다가 돌아온다.

## 3. 한계

- 파일 링크는 **렌더 시점에 존재하는 경로만** 링크한다. 답변을 읽는 사이 파일이 지워지면 눌러도 beep 만 난다.
- 공백이 포함된 절대 경로는 첫 공백에서 끊겨 링크되지 않는다(현재 예시 기준).
- 실제 클릭·NSAlert·파인더 열기는 오프스크린에서 검증할 수 없어 사용자 실측이 필요하다.
