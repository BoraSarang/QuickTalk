# v0.20–v0.22 사용자 실측 체크리스트

> 대상: **v0.20 실행 고도화 · v0.21 스크린샷/슬래시/Shortcuts · v0.22 대화별 권한**
> 빌드: 2026-10-25 작업 트리(`swift test` 499/499 · BUILD SUCCEEDED) — **배포본 아님**
> 설계·구현 요약: `docs/plans/PLAN_v0.20-0.22_execution_macos.md`
> 결과는 이 문서 아래 **"결과 기록"** 에 적는다(실패 항목은 ID + 화면/로그).

## 준비

1. 빌드 실행: `open build/Build/Products/Debug/QuickTalk.app` (또는 Xcode Run)
2. **설정 › 도구** 를 열어 현재 값을 확인한다 — 아래 항목은 값을 바꿨다가 **원래대로 되돌리는 것까지** 포함한다.
3. 화면 기록·손쉬운 사용 권한이 필요한 항목(V21-1~3)은 **시스템 설정 › 개인정보 보호 및 보안**에서 확인.
4. 앱을 재실행하면 **승인된 폴더**(v0.22)는 초기화된다 — 의도된 동작이다.

## v0.20 — 실행 고도화

| ID | 절차 | 기대 |
|---|---|---|
| V20-1 | 설정 › 도구 › **전역 자동 수락 ON** → "디스크 여유 공간 확인해 줘" | 확인 카드 **없이** 실행되고, 카드에 실제 명령·출력이 남는다 |
| V20-2 | 자동 수락 ON 상태에서 "Dock 자동 숨김 설정 켜 줘"(`defaults write` 계열) | **중요** 위험이라 확인 카드가 뜨고 **[한 번 허용]을 두 번** 눌러야 실행된다(첫 클릭은 문구·색만 바뀜) |
| V20-3 | 자동 수락 ON 상태에서 "sudo 로 … 해 줘" | **차단** + 카드에 **[터미널에서 열기]** 버튼 |
| V20-4 | **실행 중 출력 표시 ON** → 오래 걸리는 읽기 명령(예: "홈 폴더에서 큰 파일 찾아 줘") | 출력이 **실행되는 동안** 카드에 흐른다(끝난 뒤 한 번에 나오지 않음) |
| V20-5 | V20-4 실행 중 카드의 **[중단]** | 프로세스가 즉시 멈추고 "사용자가 실행을 중지했습니다." 가 남는다 |
| V20-6 | 승인 카드가 떠 있는 상태에서 응답 중지(↑ → …) | 카드가 **거부**로 정리되고 대화가 멈춘다 |
| V20-7 | **실행 제한 시간 30초** + "60초 기다렸다가 알려 줘"(`sleep 60`) | 30초 뒤 **"시간 초과(30초)"** 로 끝난다(앱이 멈추지 않음) |
| V20-8 | "/etc/hosts 를 수정해 줘" 같은 시스템 경로 쓰기 | 앱이 쓰기를 열지 않고 **[터미널에서 열기]** → `.command` 파일이 열린다. **Enter 를 눌러야** 실행된다 |
| V20-9 | "wget 설치해 줘"(`brew install`) | **터미널로 밀리지 않고** 승인 카드가 뜬다(도구 설치 경로는 예외) |
| V20-10 | V20-1~9 후 설정 원복 | 전역 자동 수락 OFF · 실행 제한 시간 60초 · 출력 표시 ON |

## 알려진 한계 (실패로 기록하지 않는다)

- **창 제어(computer use)** 는 구현하지 않았다 — 창 조작은 여전히 불가.
- **Shortcuts 자동 전송** 없음 — 초안 채움만.
- **슬래시 팔레트 키보드 탐색(↑↓·Tab)** 없음 — 클릭 선택만(Enter 처리 보존).
- **승인된 폴더는 세션 한정** — 재실행 시 초기화.
- **규칙 테스터는 실측하지 않는다** — 실제 요구 권한은 승인 뒤 샌드박스가 정한다.
- **터미널 인계 파일**은 `$TMPDIR/QuickTalk/handoff` 에 생성되고 7일 뒤 정리된다. 앱은 실행 여부를 알 수 없다.
