## 설계 의도

### 1) 타이틀바 = 대화 맥락, 버튼은 호버
- `traffic light` + **대화 제목** + **비서 배지**만 항상 보인다.
- 나머지(📌 항상 위 · 🧠 공통 메모리 · 🔖 보관 · ◫ 퀵셸프 · ⋯)는
  상단 40pt에 마우스가 올 때만 페이드 인. `✎ 새 대화`는 상단에서 빼고 `⋯` 메뉴에 둔다(사용자 요청).
- 400pt 폭에서는 6개 아이콘 + 제목이 한 줄에 빠듯하다 → 호버 중에는 **비서 배지를 이모지로 축약**해
  제목 자리를 확보한다(영문 "Scheduled job report"도 잘리지 않음). 제목이 길면 tail truncate.
- 보관함·설정 탭은 QuickShelf/`⋯`로 이동 → 상단에서 아이콘 2~3개 감소.

### 2) 응답 = 카드 없는 전체 폭
- 배경 카드 제거, 좌우 20pt, **15pt**(현재 13pt), 줄간 4.
- 도구 실행 카드는 **응답 위에 그대로** 유지(명령 → 결과 → 답변 순서).
- 하단 한 줄: 왼쪽 `1분 전 · 59.4초`(항상, 10.5pt), 오른쪽 복사·읽어주기(**호버 시에만**).

### 3) 질문 = 꼬리 말풍선
- 오른쪽 정렬, 최대 폭 82%, accent 18%, 13.5pt.
- `⋯` 메뉴는 말풍선 **바깥 오른쪽**, 호버 시에만. 우클릭 메뉴는 유지(발견성 안전장치).

### 4) 입력독 = `＋` 도구 하나
- `＋` 클릭 → 창 연결 / 웹 검색 / 음성 입력(아이콘 + 이름 + 설명).
- 유지형(음성·웹 검색)이 켜지면 `＋` 버튼이 **그 아이콘으로 바뀌고** 작은 점이 붙는다.
- 성격 구분:
  | 기능 | 성격 | 해제 |
  | --- | --- | --- |
  | 창 연결 | 1회성(시트) | 시트에서 창 선택 |
  | 웹 검색 | 이번 질문 한정 | 전송 시 자동 해제 / 메뉴에서 끄기 |
  | 음성 입력 | 유지형 | 다시 누르면 해제 |
- 왼쪽 비서 버튼은 그대로 둔다(요청).

### 5) QuickShelf = 대화 허브
- 탭: **대화 | 클립보드 | 파일 | 캡처**, 기본 = 대화.
- 맨 위 `＋ 새 대화`, 그 아래 최근/보관함(비서 이모지 · 제목 · 상대 시간 · **응답 중 점**).
- 행을 고르면 그 대화로 이동하고 **셸프가 자동으로 닫힌다**.

## 확정된 사항 (구현 반영)

1. 호버 툴바는 마우스가 상단을 벗어나면 **0.5초 뒤** 숨긴다.
2. `⋯` 메뉴 = **보관함 · 새 대화 · 툴바 항상 보기 · 설정…**.
   (사용자 요청으로 "새 대화 아이콘"은 상단 호버 도구에서 제외 — `⋯`에만 둔다.)
3. 응답 카드 제거 후 코드 블록·표는 응답 폭 전체를 쓴다.
4. 다중 대화(6a/6b)는 이번 범위에서 제외 — 다음 작업.
5. 창 기본 400×560, 최소 380×420. autosave 이름을 `QuickTalkMainPanelV31`로 올려 새 기본 크기를 적용한다.
6. `⋯`의 "툴바 항상 보기"는 설정 › 일반의 "대화 창 도구를 항상 보기"와 같은 값(`chatToolbarAlwaysVisible`).
