# 질문 호버 — 말풍선 폭 고정 + `⋯` 클릭 QA (2026-11-06)

> 상태: **폭 고정 실측 완료(2026-11-06 00:17)** — PR #102 → `da3ab52`
> 추가 수정: **`⋯` 클릭 불가 해결** (2026-11-06 01:20, 이번 배포에 포함)

> 계기: 사용자 지적 — *"질문 호버 시 가로 사이즈가 변하는 게 아니라 세로로 변하네"*
> 원인: `⋯` 메뉴를 말풍선 `HStack` 안에 넣어, 호버할 때마다 말풍선 폭이 26pt 줄고 글자가 다시 접혔다.

## 1차 수정 — 폭 고정 (PR #102)

- `⋯` 를 **레이아웃 밖**(`.overlay`)으로 옮겨 말풍선 폭·줄바꿈·높이가 호버 전후로 **완전히 동일**하게 했다.
- 호버 판정은 행 전체(`.onHover`)로 넓혔다.

## 2차 수정 — 클릭 불가 (이번)

> 계기: 사용자 지적 — *"`⋯` 가 보이긴 하는데 눌러도 메뉴가 안 열린다"*

- 원인: `⋯` 를 행 프레임 **밖**(`offset x: 16`)에 띄워 두어, 마우스가 메뉴로 가는 순간 행의
  `onHover` 가 풀리고 SwiftUI 히트 테스트도 행 밖이라 클릭이 먹지 않았다.
- 수정:
  - 질문 행 오른쪽 **20pt 를 행 프레임 안에 포함**(`.padding(.trailing, 20)`), 말풍선은 그 안쪽에 유지.
  - `⋯` 를 행의 `.overlay(alignment: .trailing)` 로 두고 `offset(x: -4)` — **행 프레임 안**에서 클릭된다.
  - 클릭 영역 `32×24` + `contentShape(Rectangle())` — 아이콘보다 넓게.
  - 행 밖으로 나가도 **0.5초 유예** 뒤 숨김(`hoverClearTask`), 메뉴 위에 있는 동안(`hoveredQuestionMenu`)은 유지.
- 답변 행·`ChatBackground` 오른쪽에도 20pt 보정을 넣어 본문 폭이 어긋나지 않게 했다.
