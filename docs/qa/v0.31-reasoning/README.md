## 동작

| 상태 | 화면 |
| --- | --- |
| 사고 중(스트리밍) | `🧠 사고 과정 — 생각 중` + 도착하는 사고 텍스트 **자동 펼침** |
| 답변 시작 | 사고 블록은 그대로, 답변 본문이 아래에 스트리밍 |
| 완료 | `› 사고 과정` **한 줄로 접힘** (턴에 저장 — 나중에 다시 볼 수 있다) |
| 완료 후 클릭 | `⌄ 사고 과정` 으로 펼침 · 다시 클릭하면 접힘 |

- 사고 과정은 답변과 **분리**한다(본문 말풍선을 오염시키지 않음).
- `Turn.reasoning` 은 옵션 — 사고 과정을 보내지 않는 모델·구버전 `history.json` 은 nil 로 읽힌다(하위 호환 테스트 3건).
- 지원 경로: OpenAI 호환 SSE `delta.reasoning_content`, Ollama NDJSON `message.thinking` / `message.reasoning_content`,
  에이전트(도구 호출) 경로 포함. Apple FM 은 사고 과정을 노출하지 않는다(계약만 채움).
- 표시 상한 24,000자 — 무한 사고로 메모리가 커지지 않게 자른다.
- `[중지]`·오류·대화 전환 시 임시 사고 텍스트는 즉시 비운다.
