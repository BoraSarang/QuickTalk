- [ ] 설정 › 도구·권한 › 승인된 앱 목록이 **비어 있음** 확인. (U3 에서 채워진다)

## U2 — 승인 카드 · 거부

**말하기**
> "TextEdit에 '안녕하세요'라고 입력해줘"

**기대**
1. `ui_snapshot` 으로 TextEdit 요소를 읽는다.
2. 승인 카드에 **앱 이름(TextEdit) · 동작(텍스트 입력) · 대상 요소 · 입력할 내용**이 보인다.
3. **"되돌릴 수 없음"** 배지가 보인다.
4. `[거부]` 를 누르면 **아무것도 입력되지 않고**, 거부 사유가 대화에 남는다.

## U3 — [이 앱 허용] · 7일 기억

**말하기**
> "TextEdit에 '두 번째 테스트'라고 입력해줘"

**기대**
1. 승인 카드에서 `[이 앱 허용]` 선택 → 실제로 입력된다.
2. 같은 요청을 **다시** 보내면 **승인 카드 없이** 실행된다(7일 승인).
3. 설정 › 도구·권한 › 승인된 앱 목록에 **TextEdit** 와 **만료일(7일 후)** 이 보인다.
4. `[해제]` 를 누르면 다음 요청부터 다시 묻는다.

## U6 — 사용자 입력 중(유휴 가드)

**말하기**
> "TextEdit에 '입력 중 테스트'라고 입력해줘"

**기대**
1. 승인 카드가 뜨면 `[한 번 허용]` 을 누른다.
2. **곧바로 다른 앱(예: TextEdit)에서 계속 타이핑**한다.
3. **"사용자가 입력 중이라 실행하지 않았습니다 — 잠시 후 다시 시도하세요."** 가 나오고 입력되지 않는다.

> 너무 빨리 멈추면 실행될 수 있다. 승인 직후 2초 이상 계속 타이핑할 것.

## U7 — 실행 도중 [중단]

**말하기**
> "TextEdit에 '첫 줄', '둘째 줄', '셋째 줄'을 각각 입력해줘"

**기대**
1. 여러 동작이 순서대로 실행된다.
2. 실행 중 **[중단]**(또는 응답 중지)을 누른다.
3. **"사용자가 중단했습니다."** 가 나오고 **다음 동작이 실행되지 않는다**.
4. 설정 › 도구·권한 › 실행 기록에 중단된 동작이 남는다.

## U8 — 31번째 동작 한도

> 수동 재현이 어렵다. 모델이 30동작을 넘게 계획해야 한다.

**말하기(시도)**
> "TextEdit에 한 글자씩 40번 입력해줘"

**기대**
- 30번째 동작 뒤 **한도 초과**로 멈추고, 31번째는 실행되지 않는다.
- 재현이 안 되면 **단위 테스트로 갈음**(`UiGuardTests` 의 한도 경계)하고 "미재현"으로 적는다.
