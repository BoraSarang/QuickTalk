# 대화 뷰 겹침·스크롤 — 조사와 수정 (2026-11-05)

> 대상: 실제 기록 `테크충이 얼마나 똑똑 한가` (20턴 · 대화 id `84DABB76-…-C0F0B76456FA`)
> 사용자 보고: "대화가 완전히 못 쓸 정도" — 턴·도구 카드가 **겹쳐 보이고**, 스크롤이 **낭치(자동으로 바닥으로 튐)** 된다.
> 검증은 전부 **오프스크린 렌더**로 했다(사용자가 앱을 쓰는 중이라 실행·종료·스크린샷 없음).

## 1. 무엇이 있었나 (실측)

| 항목 | 값 |
|---|---|
| 대화 턴 | 20 |
| 문서 높이(수정 전) | **20,821 pt** (뷰포트 1,188 pt) |
| 가장 무거운 턴 | 17번 — 도구 이벤트 13개, 명령 8,123자(거부) · 7,501자(완료), 출력 3,483/2,204자 |
| 명령만 300자로 자른 문서 높이 | 13,956 pt (약 6,900 pt 가 명령 텍스트) |

- 100% 배율에서 **겹침 재현**. 0/25/50/75/100% 스캔에서 위치마다 겹침.
- 명령을 잘라 렌더하면 **겹침 없음** → 원인은 도구 카드의 긴 명령 `Text` 하나로 좁혀졌다.

## 2. 원인

### (A) 긴 명령 텍스트의 `fixedSize(vertical:)` — 겹침
`AgentCard` 의 명령 `Text` 에 `.fixedSize(horizontal: false, vertical: true)` 가 있었다.
바깥 대화 `ScrollView` 안에서 이 조합은 **레이아웃 높이와 실제 그리기 높이를 어긋나게** 만들었다
(8,000자를 넘는 한 줄 명령에서 특히). 카드가 차지한다고 계산된 높이보다 아래로 더 그려져
**다음 턴이 그 위에 겹쳐** 놓였다. 스크롤 위치와 무관하게 발생.

수정: `fixedSize` 제거(ScrollView 는 높이를 무한히 제안하므로 고정할 이유가 없다) +
턴 내용 열이 남는 폭을 정확히 차지하도록 `.frame(maxWidth: .infinity, alignment: .leading)`.
검증: 같은 실데이터 5개 위치 스캔에서 겹침 0.

### (B) `.defaultScrollAnchor(.bottom)` — 스크롤 낭치
macOS 15 의 `defaultScrollAnchor` 는 **처음 배치할 때뿐 아니라 콘텐츠 크기가 바뀔 때도** 바닥에 다시 붙는다.
스트리밍 글자·도구 출력이 늘어날 때마다 사용자를 바닥으로 끌고 가 **과거 내용을 읽을 수 없었다**.
(v0.27 의 "스트리밍이면 무조건 따라가기"가 이를 악화시켰다.)

수정: `.defaultScrollAnchor` 제거. 자동 따라가기는 **실제 NSScrollView 오프셋**을 보고
- 사용자가 **위로** 움직이면 즉시 중단(`followsBottom = false`) — 트랙패드·휠·스크롤바·키보드 모두 포함
- 바닥에 닿으면 재개
- 새 턴 전송·"맨 아래로" 버튼·승인 카드는 예외로 무조건 바닥
로 바꿨다. 이동은 `ScrollViewProxy` 대신 `NSScrollView` 를 직접 옮긴다
(`scrollToEndOfDocument:` 는 SwiftUI `HostingScrollView` 에서 unrecognized selector 로 죽는다).

### (C) 도구 출력 상자가 항상 150pt — 빈 공간 + 안쪽 스크롤
출력은 안쪽 `ScrollView` + `.frame(maxHeight: 150)` 이었다. 바깥 스크롤 안에서는
**짧은 출력도 150pt 빈 상자**가 되고, 그 위에서 휠을 굴리면 **안쪽 스크롤이 먼저 먹어**
대화가 멈춘 것처럼 느껴졌다.

수정: 안쪽 스크롤 제거. **8줄까지** 보여 주고 길면 `전체 보기 · N자` 로 펼친다(접기 가능).
20턴 문서가 20,821 → 20,667 pt 로 줄고, 짧은 출력 카드가 내용만큼만 차지한다.

### (D) 처음 열 때 바닥에 붙지 않던 문제
복원 직후에는 문서 높이가 0인 채로 핀을 시도해 맨 위에 남았다(오프스크린 실측 `distance=19,633`).
수정: 핀을 몇 번 재시도하고, 문서 높이가 확정될 때까지 **짧은 정착 타이머(0.15s × 최대 4s)** 로 다시 맞춘다.
사용자가 그 사이 위로 올리면 즉시 포기한다. 검증: `distance=0`.
