## 1. 계기 — v0.29 이후 사용자 지적

1. **⌘Space 화면(pill)에서 비서를 고를 수 없다** — v0.28 에서 비서 버튼을 **대화 창 입력독**에만 넣었다. 사용자가 처음 요청한 화면은 pill 이었다(첨부 캡처 확인: 그라데이션 오브 + `무엇이든 물어보세요` + 보관함 아이콘).
2. **pill 의 키보드 커서·입력 글자가 아래로 치우쳐 있다** — v0.29 에서 세로 정렬을 **대화 창 입력독만** 실측해 고쳤고(1176.5 vs 1175.5), pill 은 손대지 않았다. 사용자의 2026-11-05 캡처도 pill 이었다.

원인(추측 아님 · 코드/픽셀 실측):

- pill 글자 프레임이 `PillMetrics.minTextHeight = 24`(어림값)로 고정 — 실제 `NSTextView` 1줄 상자는 `줄 높이 18.6 + 위아래 12 = 30.6`. 24pt 상자를 아래 기준선 + `textPad 13` 에 붙여 **글자·캐럿이 본체 중심보다 2.75pt 아래**에 그려졌다.
- 안내 문구는 별도 SwiftUI `Text` 오버레이 + `.padding(.top, 3)` 이라 캐럿 기준선과 더 어긋났다.

## 3. 구현

### 3.1 pill 비서 선택
- `PillModel.persona` / `personas` 추가 — `UIStore` 의 `settings.personas`·`conversation.personaID` 를 구독해 최신 상태를 유지.
- pill 입력 오른쪽·보관함 왼쪽에 **`PillPersonaButton`**(32pt 원형, 선택 시 이모지 + 체크 배지, 없으면 `person.crop.circle`).
- 메뉴 내용은 `PersonaMenuList` 로 공통화 — 헤더 `지금: …`, `비서 없음`, 비서별 체크. 대화 창 칩·입력독·pill 이 **같은 목록**을 쓴다(중복 구현 제거).
- 메뉴를 고르는 동안 pill 이 닫히지 않도록 `NSMenu.didBeginTracking/didEndTracking` 관찰 → `handleResignKey` 가드, 닫히면 패널을 다시 key 로 만들고 입력창 포커스 복귀.
- 세션이 만료돼 `startShortcutSession()` 이 새 대화를 시작해도 **pill 에서 직접 고른 비서**를 다시 적용(`reapplyPersonaIfNeeded`).

### 3.2 pill 글자·커서 세로 중심
- 1줄 상자 높이를 어림값 24 가 아니라 **`ChatInputField.lineHeight(for:) + 2 × verticalPadding`**(= 30.6)로 계산.
- 아래 여백을 `textPad` 고정이 아니라 `(capsuleHeight - textHeight) / 2` — 1줄 12.7pt, 여러 줄 13pt 로 수렴.
- 안내 문구는 SwiftUI 오버레이를 없애고 **`NSTextView` 가 직접 그린다**(`ChatTextView.placeholder`) — 캐럿과 같은 텍스트 시스템·같은 기준선. 대화 창 입력독도 같은 경로로 통일.
