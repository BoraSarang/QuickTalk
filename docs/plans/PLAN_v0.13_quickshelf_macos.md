| 항목 | 결정 |

## 1. 목표

입력창의 `＋`가 떠안고 있던 **파일 선택 · 이미지 선택 · 클립보드**에 **화면 캡처**까지 더해,
화면 오른쪽 가장자리 핸들 하나로 여는 **단일 수집 트레이(QuickShelf)** 로 통합한다.

- 대화 창과 레이아웃을 공유하지 않는다(오버레이). 대화 창이 닫혀 있어도 쓸 수 있다.
- 결과물(캡처·파일·클립보드)은 모두 **같은 카드 문법**으로 보이고, 클릭 한 번으로 대화에 들어간다.
- 클립보드 코어(2분 · 5개 · 민감 마스킹 · 사용 후 소비)는 그대로 재사용한다.

## 2. 화면 구조

### 2.1 Edge 핸들
- 크기 14×122pt(설정 88·122·160), 화면 오른쪽 끝 세로 중앙
- borderless `NSWindow`, level `.statusBar`, `collectionBehavior = [.canJoinAllSpaces, .stationary]`
- 클릭은 받고 **포커스는 뺏지 않음**; 드래그로도 열기
- 새 항목이 들어오면 `peek` 애니메이션 1회(설정으로 끔)
- 호버 시 18pt로 살짝 확장

### 2.2 QuickShelf 패널
- `NSPanel` — `.nonactivatingPanel` · `.borderless` · level `.floating`, 폭 300pt(280/300/340)
- 여는 방법: 핸들 클릭 · `⌥⌘V` · (설정) 자동 숨김 OFF면 유지
- 닫기: `Esc` · 바깥 클릭 · 핸들 재클릭 · `✕`
- 헤더: `QuickShelf` + 실시간 점 + 개수 + `⚙` + `✕`
- 탭 3개: **클립보드 / 파일·이미지 / 캡처**

### 2.3 탭별 내용

**클립보드**
- 검색 + 필터(전체·텍스트·이미지·링크)
- 카드: 이미지 썸네일 / 텍스트 3줄 / 링크 도메인 / 민감 마스킹
- 카드 하단: 종류 · 남은 시간 · 시간 게이지
- 호버 → 패널 왼쪽에 큰 미리보기(텍스트 전문 최대 900자 / 이미지)
- 클릭: 텍스트·링크 = 입력창 삽입 후 카드 제거 · 이미지 = 첨부 후 제거 · 민감 = 공개 → 사용

**파일·이미지**
- `파일 선택…`(`⌘O`) · `이미지 선택…`(`⌘⇧O`) · 드래그 앤 드롭 존
- 카드: 아이콘 · 파일명 · 종류/크기 · 추가 시각
- 클릭 = 대화 첨부(칩으로 표시), 카드는 유지(다시 쓸 수 있게)

**캡처**
- 버튼 3개: `전체 화면 ⌥⇧3` · `윈도우 ⌥⇧4 Space` · `드래그 선택 ⌥⇧4`
- 최근 캡처 썸네일(출처 배지: 전체/윈도우/드래그, 크기)
- 캡처는 **직접 지울 때까지** 유지(클립보드와 정책 다름)

## 3. 캡처 구현 (ScreenCaptureKit)

### 3.1 3모드
1. **드래그 선택** — 화면별 오버레이 창(어두운 층 + 선택 사각형 + 8개 핸들 + 돋보기 + 크기 표시 + 하단 힌트)
   - 선택 중 `Space` → 윈도우 모드 전환, `Esc` → 취소
   - 캡처 직후 툴바: 대화에 첨부 / 클립보드 / 파일로 저장 / 주석(예정)
2. **윈도우** — 마우스 아래 윈도우 강조(보라 테두리), 클릭 시 해당 창만 캡처(그림자 옵션)
3. **전체화면** — 즉시 캡처, 화면 1회 플래시 + 토스트

### 3.2 권한 · 제약
- **화면 기록 권한**(`ScreenCaptureKit`) 필요 → 최초 실행 시 안내 카드 + 시스템 설정 딥링크
- `⌘⇧3` / `⌘⇧4`는 시스템 전용 → 앱이 가로채지 않는다. **자체 단축키 `⌥⇧3` / `⌥⇧4`** 만 제공
- 전체화면 앱 위에서는 overlay 창에 `.fullScreenAuxiliary` 필요
- 다중 모니터: 모든 화면에 오버레이, 캡처는 선택된 화면 기준

## 4. 데이터 모델

```swift
struct ShelfItem: Identifiable {
  enum Kind { case clipboard, file, image, capture }
  let id: UUID
  var kind: Kind
  var title: String            // 표시용(파일명·"캡처 1284×742")
  var url: URL?                // 파일·캡처 임시 저장 경로
  var text: String?            // 클립보드 텍스트
  var imageData: Data?         // 썸네일/원본
  var createdAt: Date
  var expiresAt: Date?         // 클립보드만(2분), 캡처는 nil
  var isSensitive: Bool
  var isPinned: Bool
  var captureSource: CaptureSource?   // .fullScreen / .window / .drag
}
```
- 클립보드는 기존 `ClipboardPolicy` 유지, 캡처·파일은 `expiresAt = nil`
- 임시 파일: `~/Library/Caches/QuickTalk/Shelf/` (캡처는 원본 크기 PNG, 썸네일 480px)

## 5. 설정 (`Hub 설정 › QuickShelf`)

**패널** — 사용 on/off · 핸들 기준(화면/창) · 위치(오른쪽/왼쪽) · 높이 · 폭 · 자동 숨김 · 열기 단축키
**캡처** — 캡처 후 동작(QuickShelf/클립보드/저장) · 단축키 접두(⌥⇧/⌃⇧/직접) · 그림자 포함 · 소리 · 돋보기 · 저장 폴더 · 보관 기간
모두 기존 설정 탭과 **같은 뷰(단일 출처)**.
