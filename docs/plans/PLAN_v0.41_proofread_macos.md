# PLAN v0.41 — 입력 교정 힌트 · 오타 노트 (macOS)

> 상태: **설계 제안 · 사용자 승인 대기** (2026-11-19)
> 크기: **L(입력 경로 2곳 + 새 엔진 + 새 화면 1개)** — 사용자 요청 2026-11-19
> "대화 입력 시 사용자가 쓴 맞춤법·띄어쓰기를 보내기 전에 가볍게 알려 주면 좋겠다"
> 지원 언어: **ko + en** (`L10n.table`) · 목업: `docs/mockups/proofread/index.html`
> 이 문서는 **구현 계획이 아니라 UI·동작 제안**이다. 승인 전에는 앱 코드를 바꾸지 않는다.

## 1. 목표 / 비목표

### 목표
- 대화창과 포인터 pill에서 **보내기 직전** 맞춤법·띄어쓰기 문제를 알려 준다.
- 결과는 **[교정해서 보내기] / [그대로 보내기]** 두 갈래. 사용자가 결정한다.
- 기본값은 **켜짐**. 검사는 **이 Mac 안에서** 끝나고, 전송을 지연시키지 않는다.
- 같은 실수를 덜 반복하도록 **오타 노트**와 **발생률·교정률**을 보여 준다.

### 비목표
- 글을 대신 다듬는 AI 작문 도우미가 아니다. **의미·말투·문장 구조는 바꾸지 않는다.**
- 모든 오류를 잡지 않는다. **확실한 것만** 알려 준다(놓치는 것이 틀린 교정보다 낫다).
- 자동 전송·자동 교정이 아니다. 사용자가 버튼을 눌러야 바뀐다.
- Apple FM을 전송 경로에 넣지 않는다(§3 실측 근거).

## 2. 현재 입력·전송 경로 (코드 확인)

| 경로 | 현재 동작 | 교정 게이트를 넣을 곳 |
|---|---|---|
| 대화창 입력독 | `Enter` = 전송, `Shift+Enter` = 줄바꿈, `⌘Return` = 전송(별도 핸들러 없음), ↑ 버튼 = 전송 | `ChatInputField.onSubmit` → `store.send()` **앞** |
| 포인터 pill | `Enter` = 전송, `⌘Return` = 대화 창 열기, `Esc` = 닫기 | `PillController.submit()` → `finish(.send)` **앞** |
| 보관함·Hub·단축키 | 대화 창을 열기만 함 | 해당 없음 |
| [다시 응답]·[실행]·예약 | `UIStore.send(executionOf:)` 등 자동 경로 | **검사하지 않음** |
| `/compact` 등 슬래시 명령 | 명령 처리 | **검사하지 않음** |
| 첨부만 있고 글자 없음 | 전송 | **검사하지 않음** |

> 사용자 인식과 코드가 다르다: **`Cmd+Enter`는 전송이 아니라 pill에서 "대화 창 열기"**다. 대화창은 `Enter`가 전송이고, `⌘Return`도 별도 핸들러가 없어 `Enter`와 같이 전송된다. 카드가 떠 있을 때는 두 키 모두 **[교정해서 보내기]**로 해석한다. 설계는 두 실제 경로를 모두 게이트한다.

## 3. 엔진 실측 — Apple FM은 이 용도에 부적합

측정 환경: macOS 27.2.1(26B131) · Xcode 27.2 · Apple FM `available` · `supportsLocale(ko_KR) == true` · context 4096.

### 3.1 Apple Foundation Models
- 한국어 자체는 지원한다(`ko-Kore-KR`). 그러나 **전송 직전 힌트**에 필요한 품질·지연을 못 맞췄다.

| 시험 | 표본 | 결과 |
|---|---|---|
| 자유 교정(전체 문장 재작성) | 5문장 | 1.3~3.9초. `봬요 → 며칠요` 같은 **의미 파괴** 1건, 문장 통째 재작성 1건 |
| 구조화 편집(original→replacement) | 5문장 | 2.2~4.9초. 없는 구간(`낼까요`)을 만들거나 `오후 3시에 → 오후 3시`처럼 **없는 오류**를 만듦 |
| 띄어쓰기 전용 + 원자 보존 검증 | 12문장 | **5개 채택 / 13개 폐기**, p50 **2.04초** · 최대 **5.10초**. `몇일 → 몇 일`(정답은 `며칠`) 같은 오교정 포함 |

- 모델은 `confidence: 1.00`을 항상 돌려줘 **확신도를 필터로 쓸 수 없다.**
- 2초대 지연은 "Enter를 누르면 바로 보낸다"는 입력 리듬과 충돌한다. 타이핑 중 미리 돌려도 4096 context·문장 재작성 위험이 남는다.

### 3.2 macOS 시스템 검사기
- `NSSpellChecker`(language `ko`, 자동 언어 감지, `.correction` 요청): 11문장 중 **2건만** 검출(`할께요`, `주실수`), **교정 문자열은 없음**.
- `NaturalLanguage` 한국어 토큰화: 어절 분리는 되지만 `lemma`·품사 태그가 `OtherWord`/nil — 형태소 분석기로 쓸 수 없다.

### 3.3 결론
> **기본 엔진은 규칙(사전 + 안전한 띄어쓰기 패턴)으로 간다.**
> Apple FM은 전송 경로에서 **제외**하고, 원할 때만 돌리는 **"AI 자세히 검사(실험)"** 로 분리한다. 기본값은 꺼짐.

규칙 엔진의 한계(모르는 오류는 못 잡음)는 명확히 안내한다. 대신 **정밀도**를 우선해 "틀린 교정"을 만들지 않는다.

## 5. 검사 시점·전송 게이트

### 5.1 한 곳으로 모은다
```
[대화창 Enter / ↑] ─┐
[pill Enter] ───────┼─→ ComposerSendGate.request(text, attachments, source)
[향후 단축키 전송] ─┘        │
                             ├─ 대상 아님 → store.send() (즉시)
                             ├─ 문제 없음 → store.send() (즉시)
                             └─ 문제 있음 → pendingHint = 결과
                                            카드 표시 (전송 보류)
```
- 게이트는 **`store.send()`를 직접 부르는 UI 경로**에만 둔다. `send(executionOf:)`·예약·재응답은 건너뛴다.
- 검사 대상: 한글 음절 2자 이상, 10,000자 이하, 슬래시 명령 아님, 첨부만 아님.
- **fail-open**: 엔진 오류·16ms 초과·규칙 로드 실패 시 **조용히 그대로 전송**한다. 절대 전송을 막지 않는다.
- IME 조합 중인 글자는 보지 않는다. `ChatInputField`가 넘기는 **확정 문자열**만 검사한다(현재 전송과 같은 문자열).

### 5.2 왜 타이핑 중 검사가 아닌가
- 규칙 검사가 5ms 이하면 전송 직전에 해도 체감 지연이 없다.
- 타이핑 중 카드가 깜빡이면 방해가 되고, 문장이 완성되기 전 오탐이 늘어난다.
- Apple FM을 쓰지 않으므로 디바운스·프리페치·취소 토큰이 필요 없다. 구현이 단순하고 예측 가능하다.

### 5.3 상태
| 상태 | 진입 | 화면 | 다음 Enter |
|---|---|---|---|
| `idle` | 입력 중 | 카드 없음 | 전송 |
| `checking` | 전송 시도 | (5ms 미만, 표시 안 함) | — |
| `hint` | 문제 발견 | 카드 + 원문 유지 | 교정해서 전송 |
| `clean` | 문제 없음 | 카드 없음(전송됨) | — |
| `dismissed` | Esc | 카드 닫힘, 입력 유지 | 다시 검사 |
| `sending` | 버튼/키 | 카드 닫힘 | — |

## 6. 화면 명세

### 6.1 대화창 — 교정 카드
- 위치: 입력독 **위에 겹치는 오버레이**(좌우 12pt, 입력독과 8pt 간격). 대화 본문 높이·스크롤을 바꾸지 않는다.
- 폭: 창 폭 minus 24pt. 최소 창(420)에서도 2열 버튼이 들어간다.
- 구성:
  1. 아이콘 + **"보내기 전에 다듬을까요?"** + `N곳을 찾았어요` + 닫기(×)
  2. 수정 목록 **최대 4개**. 각 행: 카테고리 태그 · `원문` → `고친 말`. 5개 이상이면 `+N곳 더 보기`.
  3. 버튼: **[교정해서 보내기 ↩]** (채움) · **[그대로 보내기 ⌥↩]** (테두리) · **[이 대화에서 끄기]** (텍스트, 오른쪽)
  4. 푸터: `온디바이스 규칙 검사 · 3ms · 문장은 저장하지 않음`
- 색: 브랜드 바이올렛은 **주 버튼·아이콘 배지**에만. 카드 배경은 패널 톤에 바이올렛을 아주 옅게 섞고, 테두리만 브랜드 색을 낮은 채도로 쓴다(가독성). 경고색(노랑/빨강)은 쓰지 않는다 — 혼내는 느낌을 피한다.
- 카드가 떠도 입력창 포커스는 유지한다. 목록은 읽기 전용, 클릭으로 개별 적용하지 않는다(2버튼 결정을 단순하게 유지).
- 카드가 화면 위로 넘치면 목록만 스크롤하고 버튼은 항상 보인다.

### 6.2 포인터 pill — 축약 카드
- pill(380×56) 위에 **같은 폭**의 카드. 높이 약 96pt, 최대 2줄.
- 1행: `3곳 · 띄어쓰기 2 · 맞춤법 1`
- 2행: `이번주 → 이번 주 · 몇일 → 며칠` + `+1`
- 버튼: **[교정 ↩]** · **[그대로 ⌥↩]** — 두 개만. "이 대화에서 끄기"는 pill에 두지 않는다(설정에서).
- pill은 위로 자라므로 카드가 위에 붙어도 입력 기준선이 움직이지 않는다. 화면 위쪽이면 보이는 영역 안으로 클램프한다.
- Esc: 카드가 있으면 **카드만** 닫고 pill은 유지. 카드가 없으면 지금처럼 pill을 닫는다.

### 6.3 설정 — 입력 교정
- 위치: **설정 › 대화 › 입력 교정** (창 동작과 대화 목차 사이). 새 탭을 만들지 않는다 — 탭이 이미 10개다.
- 그룹:
  | 항목 | 기본 | 설명 |
  |---|---|---|
  | 입력 교정 힌트 | **켜짐** | "끄면 확인 없이 바로 보냅니다." |
  | 표시 위치 | **대화창과 pill** / 대화창만 | "pill에서는 카드를 한 줄로 줄여 보여 줍니다." |
  | 검사 기록 남기기 | **켜짐** | "틀린 구간과 고친 구간만 저장합니다. 문장 전체는 저장하지 않습니다." + **[오타 노트 열기…]** |
  | AI 자세히 검사 | **꺼짐** (실험 배지) | "Apple Intelligence로 더 살펴봅니다. 이 Mac에서 2초 안팎, 한국어 정확도가 아직 낮습니다. 전송을 막지 않습니다." |
- "대화창만"을 고르면 **pill은 검사 없이 즉시 전송**한다. 이 경우 pill 카드도 뜨지 않는다.
- 도움말 카드는 기존 3줄 형식(뭐고·언제·이렇게)을 따른다.

### 6.4 오타 노트 — 시트
- 진입: 설정의 **[오타 노트 열기…]**, 교정 후 말풍선의 `2곳 교정` 캡션(호버 툴팁), `⋯` 메뉴(선택).
- 크기: 760×620 시트(창 폭이 작으면 90%로 클램프). 표준 시트가 아니라 앱의 카드형 시트 — 기존 `RenameSheet`·`DeleteConfirmSheet` 톤.
- 구성:
  1. 헤더: `오타 노트` / `내가 자주 틀리는 표현` + 기간(7일·30일·90일, 기본 30일) + 닫기
  2. 요약 4개: **검사한 메시지 128** · **힌트가 뜬 메시지 23 (발생률 18%)** · **교정해서 보냄 17 (교정률 74%)** · **다시 고침 4**
  3. 주별 차트: 검사량(회색) vs 힌트(주황) 막대 8주 + 평균선. `Charts` 프레임워크를 추가하지 않고 SwiftUI 도형으로 그린다.
  4. 카테고리 칩: 전체 23 · 띄어쓰기 14 · 맞춤법 7 · 문장부호 2
  5. 목록: `표현` · `횟수` · `교정`(미니 바) · `마지막` · [무시]
  6. 푸터: `기록은 이 Mac에만 저장됩니다 · 90일 뒤 자동 삭제` + [모두 지우기]
- 빈 상태: `아직 기록이 없어요` + "교정 힌트를 사용하면 자주 틀리는 표현이 여기에 쌓입니다." + [닫기]
- 점수·연속일·뱃지 같은 게이미피케이션은 넣지 않는다. **반복이 줄어드는 것**이 목표다.

## 7. 키보드·마우스

| 상황 | Enter | ⌥Enter | Esc | 클릭 |
|---|---|---|---|---|
| 카드 없음 (대화창) | 전송 | — | — | ↑ 전송 (⌘Return도 전송) |
| 카드 있음 (대화창) | 교정해서 전송 | 그대로 전송 | 카드 닫기(입력 유지) | 각 버튼 |
| 카드 없음 (pill) | 전송 | — | pill 닫기 | ↑ 전송 |
| 카드 있음 (pill) | 교정해서 전송 | 그대로 전송 | 카드 닫기 | 각 버튼 |
| 카드에서 "이 대화에서 끄기" | — | — | — | 이 대화에서만 끔 |

- `⌘Return`은 pill에서 지금처럼 **대화 창 열기**다. 대화창에서는 `Enter`와 같이 전송으로 동작하며, 카드가 있으면 [교정해서 보내기]를 고른다.
- 카드가 떠 있을 때 입력을 고치면 카드를 닫고 다음 전송에서 다시 검사한다(실시간 재검사 없음).
- "이 대화에서 끄기"는 **세션 한정**. 앱을 다시 켜거나 새 대화를 열면 설정 기본값으로 돌아온다.


### 8.2 규칙 형식
- **맞춤법**: 닫힌 사전. 예: `몇일→며칠`, `할께→할게`, `웬지→왠지`, `오랫만→오랜만`, `금새→금세`, `어떻해→어떡해`, `뵈요→봬요`, `역활→역할`, `뒤쳐→뒤처`, `안되요→안 돼요`.
- **띄어쓰기**: 형태 경계가 명확한 패턴만.
  - `(할|줄|볼|될|갈|올|먹을|마실|보낼|만날|쓸|알|모를|드릴)수` → `… 수` (`수록` 제외)
  - `(할|볼|갈|올|먹을|마실|만날|보낼|쓸|알|모를|드릴)것` → `… 것`
  - `이번주/다음주/지난주/저번주` → `이번 주/…`, `이번달/다음달/지난달/저번달` → `… 달`
  - `한달/두달/세달/몇달` → `한 달/…`
  - `몇시/몇분/몇개/몇명/몇번/몇월` → `몇 시/…`
  - `잘부탁` → `잘 부탁`, `잘부탁드립니다` → `잘 부탁드립니다`
  - `부탁 드리` → `부탁드리`, `연락 드리` → `연락드리`, `말씀 드리` → `말씀드리`
- **문장부호**: `" ,"` / `" ."` / `" ?"` / `" !"` 앞 공백 제거. 숫자 `1,000`·이모지·줄임표는 건드리지 않는다.
- **금지**: `안되` 전체 치환(안됐다=불쌍하다), `한번`(문맥 의존), `이야기 하고`(명사+하다 구분), `완료 해야`(문맥 의존). 애매하면 넣지 않는다.

### 8.3 안전 필터
- URL·이메일·파일 경로(`~/`, `/Users/`, `http`, `www.`, 확장자)와 백틱 코드 구간은 건너뛴다.
- 한글 음절이 2자 미만이면 검사하지 않는다. 영어·숫자만 있는 글도 건너뛴다.
- 각 규칙은 **앞뒤 경계**를 확인한다(`이번주말` 같은 합성어 오탐 방지).
- 같은 구간에 여러 규칙이 겹치면 **가장 긴 규칙 하나**만, 적용은 뒤에서 앞으로.
- 결과는 **최대 4개**만 보여 준다(나머지는 `+N곳`). 많이 고치면 글이 내 것이 아니게 된다.
- 사용자가 [무시]한 표현은 `ProofreadIgnoreList`에 저장하고 이후 조용히 건너뛴다.

### 8.4 성능 예산
- 500자 이하: **5ms 이하**, 10,000자: **16ms 이하** (M1 기준, 구현 단계에서 `measure` 테스트로 고정).
- 규칙은 앱 시작 시 **lazy** 로드. 콜드 스타트 예산(+0ms)에 영향 없음.
- 메모리 +5MB 이하. 네트워크 0회. 새 권한 0개.

## 9. 데이터·통계

### 9.1 저장
`~/Library/Application Support/QuickTalk/proofread.json` (원자적 쓰기, 0600)
```json
{
  "version": 1,
  "entries": [
    { "id": "…", "at": "2026-11-19T09:12:00Z", "category": "spacing",
      "original": "이번주", "replacement": "이번 주", "accepted": true,
      "ruleID": "spacing.this-week", "source": "rule" }
  ],
  "daily": [
    { "day": "2026-11-19", "checks": 12, "hints": 3, "accepted": 2,
      "asIs": 1, "dismissed": 0 }
  ],
  "ignored": ["회사명", "제품명"]
}
```
- **문장 전체를 저장하지 않는다.** 구간(원문·고친 말)만. 주변 문맥도 저장하지 않는다.
- 최대 2,000개 / 90일. 일별 카운터는 400일. 오래된 것부터 정리.
- `entries`는 오타 노트 목록용, `daily`는 차트·요약용. 둘 다 로컬.

### 9.2 정의
| 지표 | 정의 | 의미 |
|---|---|---|
| 검사한 메시지 | 게이트를 통과해 전송된 메시지(교정·그대로·문제 없음) | 분모 |
| 힌트가 뜬 메시지 | 그중 1개 이상 발견 | 분자 |
| **발생률** | 힌트가 뜬 메시지 ÷ 검사한 메시지 | 얼마나 자주 틀리는가 |
| 교정해서 보냄 | [교정해서 보내기]를 고른 메시지 | — |
| **교정률** | 교정해서 보냄 ÷ 힌트가 뜬 메시지 | 힌트를 얼마나 받아들이는가 |
| 그대로 보냄 | [그대로 보내기]를 고른 메시지 | 무시율(표시만, 비난 아님) |
| 다시 고침 | 카드에서 Esc로 돌아간 횟수 | **스스로 고치려는 신호** |
| 반복 표현 | 같은 `original→replacement`가 7일 내 2회 이상 | 오타 노트 상단 |

- 발생률 분모에는 **기능이 켜져 있을 때 전송한 메시지**만 넣는다. 기능을 끈 기간은 제외.
- 표본이 20건 미만이면 비율 카드에 `표본이 적어요`를 붙이고, 지난주 대비 증감은 숨긴다.
- 문장부호·맞춤법·띄어쓰기를 **카테고리별**로 집계해 "무엇을 자주 틀리는지"를 보여 준다.

### 9.3 프라이버시
- 기록은 기본 **켜짐**이지만 즉시 끌 수 있고, [모두 지우기]로 파일을 비운다.
- 로그에는 개수·카테고리만. 원문·구간은 로그에 남기지 않는다([HARD] 로그 마스킹).
- Apple FM 실험을 켜도 **입력 전문을 외부로 보내지 않는다**(온디바이스). 네트워크 호출 없음.
- 앱을 삭제하면 Application Support와 함께 사라진다. 별도 동기화 없음.

### 테스트
- **규칙**: 각 항목의 긍정/부정 예문, 경계(`이번주말`, `할수록`), URL·코드·이메일 무시, 겹침, 역순 적용, 멱등성.
- **게이트**: 대화창 Enter, ↑, pill Enter, `⌘Return`, 슬래시 명령, 첨부만, 자동 전송, 기능 끔, "대화창만".
- **통계**: 분모 0, 표본 부족, 90일 정리, 무시 목록, [모두 지우기].
- **성능**: 500자/10,000자 `measure`, 메모리.
- **렌더**: `docs/qa/v0.41-proofread/` — 대화창 카드(한/영·라이트/다크), 힌트 없음, pill(다크/라이트), 설정(한/영·라이트/다크), 오타 노트(데이터/빈 상태·한/영·라이트/다크). 13장 렌더 완료.
