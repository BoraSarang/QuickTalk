# PLAN_v0.11_quick-settings_macos.md
> 생성일: 2026-10-19 | 플랫폼: macos | 작성자: OpenCode
> 목표: 대화 창 "설정" 탭을 메뉴바 Hub 설정 탭과 **동일한 공유 뷰**로 재설계 — 조작은 활성 AI·모델 선택만, 상태는 표시

## 1. 배경 (문제)
- 기존 대화 창 설정 탭은 T-10에서 설정을 독립 창으로 분리할 때 "설정 요약 4줄 + 설정 열기…" 스텁만 남았다
- 대화 창은 460×560 고정 + 상단 정렬이라 내용(약 120pt) 외 **약 440pt가 빈 공간** → "제대로 만들지도, 없애지도 않은 중간 상태"

## 2. 사용자 지시 (순서)
1. 설정 화면이 왜 이러냐 → 목업을 만들라 → 3안(A 없애기 / B 제대로 / C 요약+점검) 제시 → **B안** 선택
2. 단축키는 불필요. **AI 관련만** 남긴다(프로바이더·모델 **선택만**, 추가·삭제 없음)
3. Whisper·음성 등은 한 번 정하고 거의 안 바꾸므로 이 탭에서 제외 → `전체 설정 보기`로
4. **C안의 상태 표시는 유지** (상태 카드)
5. **메뉴바 Hub 설정 탭과 동일하게** (설정 창 공유) + 목업의 AI 요소 반영
6. 표시 토글 3종 삭제, 모델 드롭다운 **가로 꽉 채움**
7. **custom 프로필 준수** — 네이티브 팝업 컨트롤 금지(자체 카드 스타일로 구현)

## 3. 범위
- 신규: `QuickSettingsCardsView` — 메뉴바 Hub 설정 탭과 대화 창 설정 탭이 함께 쓰는 **단일 출처 뷰** (`MenuBarHubView.swift` 내부, 새 파일 없음)
- `UIStore`: AI 빠른 설정 상태(마지막 호출 결과 `lastAICall`, `modelOptions`, `refreshModels()`, `setActiveProvider/setActiveModel`, 상태 문구)
- `ContentView`: 3번째 탭 내용을 공유 뷰로 교체, `--panel-tab=<chat|archive|settings>` QA 플래그 추가
- `SettingsView`(전면 설정 창): 변경 없음 — 편집·추가·삭제는 여기서만(native 규칙 유지)
- 표시 토글 3종은 전면 설정 창(일반)에만 존재

## 4. 화면 구성 (위→아래)
1. `모든 설정 열기` 카드 → 전면 설정 창
2. `활성 AI` — 프로바이더 라디오 행(사용 중 표시, 클릭 = 전환)
3. `모델` — 자체 드롭다운(현재 값 + `⌄`, 누르면 카드 안 라디오 목록) + `⟳` 목록 조회, Apple FM은 잠금 + 사유
4. `상태` (읽기 전용) — AI 연결(마지막 호출 결과, 실패 시 에러코드) / 호출 단축키(전역 등록) / 음성(엔진·Whisper 준비)
5. 안내 문구(진입점 상태)

## 5. 성능 예산
- budgets.json 준수(Cold Start ≤1.5s, 메모리 ≤300MB). 모델 목록은 `⟳`를 눌렀을 때만 조회(상주 요청 금지)

## 6. 에러 코드
- 재사용: `E-MAC-NET-0001`(호출 실패), `E-MAC-NET-0002`(미설정·모델 없음·목록 조회 실패). 실패는 목업으로 숨기지 않고 상태 행에 코드로 표시
