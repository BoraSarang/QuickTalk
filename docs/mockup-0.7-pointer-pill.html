04 화면 가장자리 규칙

기본 — 포인터에서 오른쪽으로

캐럿은 포인터 x에, 캡슐은 오른쪽으로 펼침. 세로는 캐럿 중심 = 포인터 y.

오른쪽 공간 부족 — 왼쪽으로 뒤집기

화면 오른쪽 끝 12pt 안쪽이면 캡슐을 왼쪽으로 펼치고, 캐럿은 포인터에 그대로 둔다.

아래 공간 부족 — 위로 뒤집기

Dock·화면 하단에 닿으면 캡슐을 위로 올린다. 캐럿 x는 고정.
