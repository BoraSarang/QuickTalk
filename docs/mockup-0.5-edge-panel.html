QuickTalk 목업 v0.5 — Edge 패널 클립보드

삼성 Edge 패널 방식 — 화면 오른쪽 가장자리의 얇은 핸들을 누르면, 대화 창 위로 클립보드 패널이 슬라이드되어 나옵니다. 평소에는 숨겨져 있고 입력창과 레이아웃을 공유하지 않습니다.

이번 목업에서 확정하려는 것
  • 핸들 — 평소 폭 14pt(높이 122pt) 반투명 보라. 호버 시 18pt, 새 항목이 들어오면 한 번 살짝 부풀어(peek) 알린다.
  • 열기/닫기 — 핸들 클릭 또는 드래그 · 패널 바깥(어두운 영역) 클릭 · Esc · ⌥⌘V 전역 단축키.
  • 겹침 — 패널은 대화 본문·입력창 위(또는 다른 앱 위)에 뜬다(폭 268pt — 실제 앱에선 300pt). 레이아웃은 전혀 변하지 않는다.
  • 사용 후 소비 — 카드를 누르면 입력창 삽입(텍스트·링크) 또는 첨부(이미지·파일) 후 그 카드가 사라진다. 민감 항목은 첫 클릭 공개, 두 번째 클릭 사용.
  • 호버 미리보기 — 카드에 올리면 패널 왼쪽에 크게 뜬다(텍스트 전문 / 이미지 224×120).
  • 로그·캡처에 클립보드 내용을 남기지 않는다(기존 [HARD] 유지). 유지 2분 · 최대 5개.

상태 닫힘 → 열림 → 호버 미리보기 (첫 번째 창은 실제로 눌러 볼 수 있습니다)

구현 메모 실제 앱에 옮길 때

구조
  • 핸들 — borderless `NSWindow`(level `.statusBar`, `collectionBehavior` = `.canJoinAllSpaces · .stationary`), 14×110pt를 화면 오른쪽 끝에 고정. 클릭은 받고 포커스는 뺏지 않는다.
  • 패널 — `NSPanel`(`.nonactivatingPanel` · `.borderless` · level `.floating`), 폭 300pt. 열려도 작업 중인 앱의 포커스가 유지된다. Esc·바깥 클릭으로 닫힘.
  • 재사용 — 기존 `Clipboard.swift`(2분 · 5개 · 민감 마스킹)와 소비 로직을 그대로 쓰고 UI만 교체. 오른쪽 레일은 제거(또는 설정에서 선택).
  • 리스크 — 전체 화면 앱에서는 핸들을 숨기고 메뉴바 아이콘/단축키로 대체. 다중 모니터는 "주 화면" 기준.
  • 작업량 — 핸들·패널 껍데기 0.5일 · 카드/미리보기 이식 0.5일 · 설정 0.5일 (기존 코어 재사용 전제).
정해 주실 것
  • 핸들 기준 — 화면 가장자리(모든 앱 위, 삼성과 동일) vs QuickTalk 창 안
  • 패널 폭 — 300pt(기본) / 340pt(넓게)
  • 기존 오른쪽 레일 — 제거하고 Edge 패널로 일원화 vs 둘 다 유지
  • 이미지 카드 클릭 — 첨부로 추가 / 이미지 복사(클립보드로 되돌리기)
